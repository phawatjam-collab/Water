# เอกสารข้อกำหนดความต้องการซอฟต์แวร์ฉบับสรุป (Mini SRS)
## โครงการระบบบริหารจัดการน้ำประปาหมู่บ้านวังยาง (Smart Village Waterworks Management System)

**หน่วยงานผู้ใช้งาน:** กองทุนระบบการประปาหมู่บ้านวังยาง หมู่ที่ 3 ตำบลวังยาง อำเภอวังยาง จังหวัดนครพนม  
**รหัสโครงงาน:** SE-2567-WTR-MINI | **เวอร์ชัน:** 1.0 (ฉบับเสนอประเมินผลโครงงาน)  
**ไฟล์ต้นแบบอ้างอิง (Axure RP Prototype):** `Plumber_ver-1003-gu-tam-kon-dew-i-sus.rp`  
**คลังซอร์สโค้ด (GitHub Repository):** `https://github.com/phawatjam-collab/Water` (Branch: main)  

---

### 1. บทสรุปผู้บริหารและความเป็นมาของโครงงาน (Executive Summary)
กิจการประปาหมู่บ้านวังยางดูแลผู้ใช้น้ำจำนวน 400 ครัวเรือน เดิมใช้การบันทึกข้อมูลด้วยสมุดกระดาษ ทำให้เกิดปัญหาเลขอ่านมาตรวัดน้ำคลาดเคลื่อน เลขถอยหลัง การคำนวณค่าน้ำล่าช้า การติดตามหนี้ค้างชำระไม่เป็นระบบ และการจัดทำหลักฐานการเบิกจ่ายค่าตอบแทนผู้จัดเก็บร้อยละ 10 ขาดความคล่องตัว 

คณะผู้จัดทำจึงได้พัฒนาระบบสารสนเทศบนเว็บด้วยภาษา PHP ร่วมกับฐานข้อมูล MySQL เพื่อรองรับการจดมาตรวัดน้ำผ่านสมาร์ตโฟนตามลำดับเส้นทางจริง การออกใบแจ้งหนี้และใบเสร็จรับเงิน (แบบ ป.31/32) การสร้าง QR Code ชำระเงินผ่านพร้อมเพย์ และการควบคุมบัญชีลูกหนี้ (แบบ กค.4) อย่างครบวงจร

### 2. ตารางกำหนดบทบาทและสิทธิ์การใช้งานระบบ (User Roles & Permissions)

| กลุ่มผู้ใช้งาน | ตำแหน่งจริงในชุมชน | ขอบเขตหน้าที่และความรับผิดชอบ | หน้าจอเริ่มต้น |

| **ประชาชนทั่วไป (User)** | ประชาชน / บุตรหลาน | ค้นหาค่าน้ำด้วยหมายเลขโทรศัพท์หรือบ้านเลขที่ สแกนจ่ายเงิน และแจ้งจุดท่อแตกฉุกเฉิน | `index.php` |

### 4. สถาปัตยกรรมระบบและการเชื่อมโยงภาพร่างต้นแบบ (Architecture & Prototype)

- **Presentation Tier:** Responsive Web รองรับสมาร์ตโฟนและคอมพิวเตอร์ (HTML5, Vanilla JS, Bootstrap 5)
- **Application Tier:** ภาษา PHP 8 ดำเนินการคำนวณค่าน้ำ ตรวจจับความผิดปกติ และควบคุมสิทธิ์เข้าถึง (RBAC)
- **Data Storage Tier:** ฐานข้อมูล MariaDB/MySQL (InnoDB, utf8mb4) รองรับธุรกรรม ACID และตารางจริง 12 ตาราง
- **Integration Tier:** PromptPay EMVCo QR Code, การสแกนผ่านกล้องมือถือ และการส่งออกตารางเป็น Excel

**ภาพหน้าจอต้นแบบในไฟล์ Axure RP (`Plumber_ver-1003-gu-tam-kon-dew-i-sus.rp`):**
1. หน้าค้นหาข้อมูลค่าน้ำประชาชน (Screen 1) $\rightarrow$ `index.php`
2. หน้าบันทึกการอ่านมาตรวัดน้ำภาคสนาม (Screen 5) $\rightarrow$ `meter_reading.php`
3. หน้าบันทึกรับเงินและใบเสร็จ ป.31/32 (Screen 7) $\rightarrow$ `finance_billing.php`
4. หน้าใบสำคัญเบิกจ่ายค่าตอบแทน 10% (Screen 9) $\rightarrow$ `finance_billing.php`
5. หน้างบดุลประจำเดือน (Screen 18) $\rightarrow$ `executive_reports.php`
6. หน้าจัดพิมพ์สติกเกอร์ QR Code (Screen 30) $\rightarrow$ `print_qr_labels.php`
