คู่มือการติดตั้งและใช้งานระบบจริง (XAMPP Production Manual)
ระบบบริหารจัดการน้ำประปาหมู่บ้านอัจฉริยะ (Smart ERP)

กองทุนระบบการประปาหมู่บ้านวังยาง หมู่ที่ 3 ตำบลวังยาง อำเภอวังยาง จังหวัดนครพนม

⚙️ ข้อกำหนดคุณสมบัติของระบบ (System Specifications)

🖥️ ฝั่งเครื่องแม่ข่าย (Server Requirements):
• OS: Windows 10/11 (64-bit) หรือ Ubuntu 22.04 LTS
• CPU: Intel Core i3 / Ryzen 3 ขึ้นไป (2.0 GHz+)
• RAM: 4 GB ขึ้นไป (แนะนำ 8 GB)
• Software: XAMPP for Windows (PHP 8.0 - 8.2)
• DB: MariaDB 10.4 / MySQL (InnoDB, utf8mb4)
📱 ฝั่งเครื่องลูกข่าย (Client Requirements):
• อุปกรณ์: คอมพิวเตอร์, โน้ตบุ๊ก, แท็บเล็ต, สมาร์ตโฟน
• Browser: Google Chrome, Microsoft Edge, Safari
• Screen: รองรับ Responsive 360px ถึง 1920px
• กล้องมือถือ: สแกน QR Code หน้าบ้านผู้ใช้น้ำ
• Printer: เครื่องพิมพ์ A4/A5 สำหรับพิมพ์ใบเสร็จ ป.31/32

🔑 บัญชีผู้ใช้งานระบบสำหรับการทดสอบ (Default Accounts)

ชื่อบัญชี (Username) รหัสผ่าน ระดับสิทธิ์ (Role) หน้าที่ความรับผิดชอบในชุมชน
admin ไม่ต้องกรอก Superadmin ประธานกองทุน/ผู้ใหญ่บ้าน: คุมระบบทั้งหมด อนุมัติฎีกา
staff / finance ไม่ต้องกรอก Staff เหรัญญิก/ช่างจด: จดมิเตอร์ ตัดเงิน ใบเสร็จ ป.31/32 หนี้ กค.4
member ไม่ต้องกรอก Member สมาชิกผู้ใช้น้ำ (WY-002): ดูกราฟใช้น้ำ สแกนจ่ายพร้อมเพย์
user ไม่ต้องกรอก User ประชาชนทั่วไป: เช็คยอดด้วยเบอร์โทร สแกนจ่าย แจ้งท่อแตก

1. ขั้นตอนการติดตั้งและการเริ่มต้นระบบ (Installation & Setup)

XAMPP Manual • ส่วนที่ 1
ขั้นตอนที่ 1: วางไฟล์โปรเจกต์ลงใน htdocs
นำโฟลเดอร์โปรเจกต์ plumber ไปวางในไดเรกทอรี htdocs ของ XAMPP เช่น D:\Games\xamppp\htdocs\plumber หรือ C:\xampp\htdocs\plumber
ขั้นตอนที่ 2: เริ่มต้นบริการ Apache และ MySQL ใน XAMPP Control Panel
เปิดโปรแกรม XAMPP Control Panel แล้วกดปุ่ม [Start] ที่แถวของ Apache (Port 80) และ MySQL (Port 3306) โดยสังเกตว่าทั้งสองโมดูลเปลี่ยนเป็นแถบสีเขียวแสดงว่าบริการพร้อมทำงาน
ขั้นตอนที่ 3: เปิดใช้งานและระบบสร้างฐานข้อมูลอัตโนมัติ (Zero-Config DB Bootstrap)
เปิดเว็บบราวเซอร์แล้วพิมพ์: http://localhost/plumber/index.php
กลไกเบื้องหลัง: ไฟล์ api/db.php จะตรวจสอบว่ามีฐานข้อมูล db_city_water_supply หรือไม่ หากยังไม่มี ระบบจะสร้างฐานข้อมูลและนำเข้าตารางพร้อมข้อมูลสมาชิก 400 ครัวเรือนจาก database.sql ให้โดยอัตโนมัติทันที

📡 การเชื่อมต่อใช้งานผ่านมือถือในเครือข่าย Wi-Fi สำนักงานประปา:

1. ตรวจสอบหมายเลข IP ของเครื่อง Server โดยเปิด Command Prompt แล้วพิมพ์ ipconfig (เช่น 192.168.1.100)
2. ให้เจ้าหน้าที่เดินจดมิเตอร์เชื่อมต่อสมาร์ตโฟนกับสัญญาณ Wi-Fi เดียวกันกับเครื่อง Server
3. เปิดเบราว์เซอร์บนมือถือ แล้วพิมพ์: http://192.168.1.100/plumber/
4. เจ้าหน้าที่สามารถเดินจดมิเตอร์หรือประชาชนสามารถเช็คยอดค่าน้ำได้ทันทีแบบ Local LAN ออฟไลน์ 100%

📱 2.1 หน้าบริการประชาชนและการค้นหาค่าน้ำ (index.php)

ขั้นตอนการใช้งานสำหรับชาวบ้าน:
1. เปิดหน้าเว็บ index.php
2. ในช่องค้นหา "ตรวจสอบยอดค่าน้ำประปาของท่าน" พิมพ์หมายเลขโทรศัพท์ 10 หลัก (เช่น 0812345678) หรือบ้านเลขที่
3. กดปุ่ม [🔍 ค้นหาค่าน้ำ]:
    • ระบบจะแสดงการ์ดยอดค่าน้ำ: ชื่อเจ้าของบ้าน, ปริมาณน้ำที่ใช้, ยอดเงินรวมสุทธิ
    • กดปุ่ม [📱 ชำระเงินด้วย QR Code พร้อมเพย์] เพื่อเปิดภาพ QR Code มาตรฐาน EMVCo ที่มียอดเงินตรงตามสตางค์จริง แล้วใช้แอปธนาคารสแกนจ่ายได้ทันที
4. หากพบท่อแตกหรือน้ำไม่ไหล สามารถเลื่อนลงมากรอกแบบฟอร์ม "แจ้งเหตุท่อแตก / น้ำรั่ว" ด้านล่าง พร้อมระบุเบอร์โทรและจุดเกิดเหตุ

📲 2.2 หน้าเดินจดมิเตอร์ภาคสนามตามเส้นทางจริง (meter_reading.php)

ขั้นตอนการใช้งานสำหรับเจ้าหน้าที่จดมิเตอร์:
1. ล็อกอินด้วยบัญชี Staff แล้วเลือกเมนู "จดมิเตอร์น้ำ"
2. เลือก "งวดเดือน" ที่ต้องการจด (เช่น 8-2567)
3. รายชื่อผู้ใช้น้ำจะถูกเรียงตามลำดับหน้าบ้านจริง (seq_no) ตั้งแต่บ้านหลังแรกถึงหลังสุดท้าย
4. การบันทึกเลขอ่านทำได้ 2 วิธี:
    • สแกน QR Code: กดปุ่ม [📷 สแกน QR] เปิดกล้องสแกนสติกเกอร์ที่ติดบนมิเตอร์น้ำ ระบบจะกระโดดไปที่แถวบ้านนั้นให้อัตโนมัติ
    • พิมพ์ตัวเลข: แตะที่ช่อง "เลขครั้งนี้" แล้วพิมพ์ตัวเลขมิเตอร์
5. การประมวลผลอัตโนมัติ:
    • ระบบคำนวณหน่วยใช้ = เลขใหม่ - เลขเดิม
    • คิดค่าน้ำตามสูตร: (หน่วย x 7 บาท) + ค่าบำรุง 10 บาท + หนี้ค้างเก่า = ยอดสุทธิ
    • บันทึกข้อมูลลงฐานข้อมูลทันทีแบบ Real-time Auto-save
6. ระบบแจ้งเตือนความผิดปกติ: หากกรอกตัวเลขน้อยกว่าครั้งก่อน ระบบจะขึ้นแถบสีแดงแจ้งเตือนทันที ป้องกันการดูเลขผิดหรือมิเตอร์หมุนกลับ

💳 3.1 การตัดรับชำระเงินและดูใบเสร็จด่วน (Tab 1: #pane-collection)

1. เปิดหน้า finance_billing.php แล้วเลือกงวดเดือนที่ต้องการจัดการ
2. พิมพ์เบอร์โทรศัพท์หรือชื่อผู้ใช้น้ำในช่องค้นหาเพื่อค้นหาบิล
3. เมื่อรับเงิน ให้กดปุ่ม [✅ รับชำระ]:
    • สถานะจะเปลี่ยนเป็น PAID (ชำระแล้ว) สีเขียวทันที (Optimistic UI)
    • ออกเลขที่ใบเสร็จ RC-YYYYMM-XXX อัตโนมัติ
    • มี Toast แจ้งเตือนสีเขียวพร้อมปุ่ม [🖨️ พิมพ์ใบเสร็จ]
4. กดปุ่ม [🧾 ใบเสร็จ] เพื่อเปิดหน้าต่าง Quick Receipt Modal ป๊อปอัปพรีวิวใบเสร็จ ป.31/32 พร้อมสั่งพิมพ์ได้ในเสี้ยววินาทีโดยไม่ต้องสลับหน้าจอ
5. กดปุ่ม [📥 ส่งออก Excel] หากต้องการดาวน์โหลดรายงานสรุปการจัดเก็บเป็นไฟล์ Excel

⚠️ 3.2 ทะเบียนคุมหนี้ค้างชำระ กค.4 และหนังสือเตือน (Tab 3: #pane-arrears)

1. คลิกแท็บ "3. ทะเบียนคุมหนี้ค้างชำระ (กค.4)"
2. เลือกระดับความเร่งด่วนตามอายุหนี้: 1 เดือน, 2 เดือน, หรือ 3 เดือนขึ้นไป (หนี้วิกฤต)
3. กดปุ่ม [✉️ ออกหนังสือเตือน]: เปิดเอกสารหนังสือเตือนระงับการใช้น้ำชั่วคราว ดึงยอดหนี้รวมและกำหนดเส้นตายชำระ 7 วัน พร้อมสั่งพิมพ์ไปส่งที่บ้านลูกหนี้
4. กดปุ่ม [💳 ตัดชำระ]: สลับหน้าจอกลับไปยังแท็บ 1 ทันที พร้อมกรอกชื่อลูกหนี้ลงช่องค้นหาให้อัตโนมัติเพื่อรับเงินได้ทันที 1 คลิก

📜 3.3 ฎีกาเบิกจ่ายและซิงค์ค่าตอบแทนผู้จัดเก็บ 10% (Tab 4: #pane-vouchers)

1. คลิกแท็บ "4. ฎีกาเบิกจ่ายเงิน (10% & ค่าใช้จ่าย)"
2. กดปุ่ม [🔄 ซิงค์ค่าตอบแทน 10%]:
    • ระบบจะคำนวณ: ยอดค่าตอบแทน = ยอดรับชำระจริงในงวดนั้น x 10%
    • สร้างฎีกาเบิกจ่ายค่าตอบแทนให้อัตโนมัติ พร้อมแปลงตัวเลขเป็นตัวอักษรบาทไทย

💾 4.2 ระบบสำรองฐานข้อมูล 1-Click Backup (api/backup.php)

เพื่อความปลอดภัยสูงสุดของข้อมูลการเงินชุมชน ให้ดำเนินการสำรองข้อมูลเป็นประจำ:
1. เข้าสู่ระบบด้วยบทบาท Admin
2. ไปที่เมนู "สำรองฐานข้อมูล" หรือพิมพ์ URL: http://localhost/plumber/api/backup.php
3. ระบบจะทำการดาวน์โหลดไฟล์ backup_city_water_YYYY-MM-DD_HH-ii-ss.sql ลงเครื่องทันที
4. แนะนำให้คัดลอกไฟล์นี้ลง Flash Drive หรือ External HDD ทุกสิ้นเดือนหลังปิดงวดบัญชี

🔄 4.3 ขั้นตอนการกู้คืนข้อมูล (Database Restore)

หากคอมพิวเตอร์สำนักงานเกิดความเสียหายและต้องย้ายไปลงเครื่องใหม่:
1. ติดตั้งโปรแกรม XAMPP บนเครื่องใหม่ และเปิดบริการ MySQL
2. เข้าไปที่ http://localhost/phpmyadmin
3. คลิกแท็บ "นำเข้า (Import)" เลือกไฟล์ .sql สำรองล่าสุด แล้วกด "นำเข้า / Go"
4. ข้อมูลสมาชิก 400 ราย และประวัติการเงินทั้งหมดจะกลับคืนมาสมบูรณ์ 100%

🛠️ ปัญหาที่พบบ่อยและแนวทางแก้ไข (Troubleshooting Matrix)

เข้าเว็บไม่ได้ (Cannot Connect) ลืมกด Start โมดูล Apache ใน XAMPP เปิด XAMPP Control Panel กดปุ่ม Start ที่ Apache
