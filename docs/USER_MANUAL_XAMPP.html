1.1 คุณสมบัติและความต้องการของระบบ (System Specifications)

เพื่อให้ระบบสามารถทำงานได้อย่างมีประสิทธิภาพและเสถียรภาพสูงสุด อุปกรณ์คอมพิวเตอร์และเซิร์ฟเวอร์ควรมีคุณสมบัติขั้นต่ำดังนี้:

• เครื่องแม่ข่าย (Server Requirements): ระบบปฏิบัติการ Windows 10/11 (64-bit) หรือ Linux Ubuntu LTS, หน่วยประมวลผล Intel Core i3 หรือ AMD Ryzen 3 ขึ้นไป, หน่วยความจำ RAM 4 GB ขึ้นไป (แนะนำ 8 GB), พื้นที่จัดเก็บข้อมูลว่างอย่างน้อย 500 MB และติดตั้งแพ็กเกจ XAMPP (Apache 2.4, PHP 8.0-8.2, MariaDB 10.4)
• เครื่องลูกข่าย (Client Devices): คอมพิวเตอร์สำนักงานหรืออุปกรณ์สมาร์ตโฟน (Android/iOS) พร้อมเว็บเบราว์เซอร์ Google Chrome, Microsoft Edge, Mozilla Firefox รุ่นปัจจุบัน และกล้องสำหรับสแกน QR Code หน้าบ้าน

1.2 ขั้นตอนการติดตั้งและเริ่มต้นระบบ (Installation Steps)

1. นำโฟลเดอร์โครงการไปวางไว้ในไดเรกทอรีเว็บเซิร์ฟเวอร์ของ XAMPP ที่ C:\xampp\htdocs\plumber หรือ D:\Games\xamppp\htdocs\plumber ตามเส้นทางการติดตั้งในเครื่องคอมพิวเตอร์ของท่าน
2. เปิดโปรแกรม XAMPP Control Panel จากนั้นคลิกปุ่ม [Start] ที่โมดูล Apache และ MySQL ให้แถบสถานะเปลี่ยนเป็นสีเขียว
3. เปิดโปรแกรมเว็บเบราว์เซอร์ แล้วพิมพ์ที่อยู่ http://localhost/plumber/ เพื่อเข้าสู่หน้าจอแรกของระบบ

1.3 ระบบติดตั้งฐานข้อมูลอัตโนมัติ (Zero-Configuration Database)

ไฟล์ api/db.php มีฟังก์ชันตรวจสอบความมีอยู่ของฐานข้อมูล db_city_water_supply โดยอัตโนมัติ หากยังไม่มีฐานข้อมูล ระบบจะสร้างฐานข้อมูลและนำเข้าโครงสร้างตารางพร้อมข้อมูลเริ่มต้น 400 ครัวเรือนจากไฟล์ database.sql ให้ทันทีโดยที่ผู้ใช้ไม่ต้องเข้าไปดำเนินการผ่าน phpMyAdmin

2.1 การจัดพิมพ์แผ่นสติกเกอร์รหัส QR Code ติดหน้าบ้าน (print_qr_labels.php)

ก่อนเริ่มรอบการจัดเก็บค่าน้ำ เจ้าหน้าที่สามารถจัดทำแผ่นสติกเกอร์ QR Code ประจำตัวมาตรวัดน้ำของแต่ละครัวเรือนเพื่อนำไปติดที่ฝาครอบมาตรวัดน้ำหน้าบ้านได้ดังนี้:

1. เข้าสู่หน้าจอ print_qr_labels.php ผ่านแถบเมนูด้านข้าง
2. เลือกรอบบิลและโซนจ่ายน้ำที่ต้องการพิมพ์ ระบบจะจัดวางแบบฟอร์มสติกเกอร์ขนาดมาตรฐาน A4 (มีรูปแบบ 12 ป้าย/แผ่น และ 24 ป้าย/แผ่น)
3. สั่งพิมพ์ลงบนกระดาษสติกเกอร์กันน้ำเพื่อนำไปปิดผนึกที่ฝาครอบมิเตอร์น้ำของแต่ละครัวเรือน

2.2 การเดินจดบันทึกมาตรวัดน้ำภาคสนาม (meter_reading.php)

ช่างจดบันทึกมาตรวัดน้ำสามารถเปิดใช้งานระบบผ่านสมาร์ตโฟนเพื่อบันทึกตัวเลขตามเส้นทางจริงได้ดังขั้นตอนต่อไปนี้:

1. เปิดสมาร์ตโฟนเชื่อมต่อเครือข่าย แล้วเปิดหน้า meter_reading.php
2. เลือกรอบเดือนที่กำลังจด (เช่น 8-2567) ระบบจะดึงรายชื่อผู้ใช้น้ำเรียงลำดับตามเส้นทางเดินจริง (seq_no) ตั้งแต่คุ้มเหนือจรดคุ้มใต้
3. การระบุตัวตนครัวเรือนทำได้ 2 วิธี คือ: (ก) กดปุ่ม [📷 สแกน QR] เพื่อส่องกล้องมือถือไปที่สติกเกอร์หน้าบ้าน หรือ (ข) พิมพ์ค้นหาด้วยบ้านเลขที่ในช่องค้นหาด่วน

2.3 การป้อนเลขอ่านและระบบตรวจจับค่าผิดปกติ (Anomaly Detection)

เมื่อป้อนตัวเลขอ่านครั้งนี้ (Current Reading) ระบบจะคำนวณจำนวนหน่วยใช้น้ำสดทันทีตามสูตร: หน่วย = เลขครั้งนี้ - เลขครั้งก่อน

• กรณีเลขถอยหลัง (Current < Previous): ระบบจะแจ้งเตือนแถบสีแดงและไม่อนุญาตให้บันทึก เพื่อป้องกันการจดสลับหลัก
• กรณีใช้น้ำพุ่งสูงเกิน 3 เท่า: ระบบจะแสดงข้อความเตือนให้ตรวจสอบจุดรั่วซึมภายในบ้าน
• กดปุ่ม [บันทึก] ข้อมูลจะถูกจัดเก็บเข้าตาราง meter_readings ทันที และแถบ Progress Bar ด้านบนจะปรับปรุงความคืบหน้างวด

3. หน้าจอแสดงรายละเอียด: ชื่อผู้ใช้น้ำ, บ้านเลขที่, งวดเดือน, เลขอ่านเดิม-ใหม่, จำนวนหน่วย, ยอดสุทธิ และปุ่มเปิดภาพ QR Code ชำระเงินผ่านพร้อมเพย์ตามยอดเงินจริง

3.2 การบันทึกรับชำระเงินและออกใบเสร็จรับเงิน (แบบ ป.31/32)

เมื่อสมาชิกนำเงินมาชำระที่ทำการกองทุน เหรัญญิกดำเนินการบันทึกในหน้า finance_billing.php (แท็บ 1: บันทึกรับเงิน) ดังนี้:

1. ค้นหาชื่อหรือบ้านเลขที่ของสมาชิกผู้มาชำระเงิน
2. กดปุ่ม [✅ รับชำระ] สถานะบิลจะเปลี่ยนเป็น PAID ทันที พร้อมบันทึกวันที่และชื่อผู้รับเงินลงฐานข้อมูล
3. กดปุ่ม [🧾 ใบเสร็จ] หน้าต่างป๊อปอัปใบเสร็จ ป.31/32 จะแสดงขึ้นพร้อมตัวอักษรบาทไทยถูกต้องตามระเบียบ จากนั้นสั่งพิมพ์ลงกระดาษส่งมอบให้ชาวบ้านได้ทันที

3.3 การควบคุมบัญชีลูกหนี้ค้างชำระ (แบบ กค.4 ในแท็บ 3)

1. เลือกแท็บ "ทะเบียนคุมหนี้ กค.4" เพื่อดูรายชื่อผู้ค้างชำระ โดยสามารถกรองตามอายุหนี้: ค้าง 1 เดือน, 2 เดือน, หรือ 3 เดือนขึ้นไป
2. กดปุ่ม [✉️ พิมพ์เตือน] เพื่อพิมพ์หนังสือแจ้งเตือนระงับการใช้น้ำกำหนดชำระภายใน 7 วัน
3. หากลูกหนี้นำเงินมาชำระ ให้กดปุ่ม [💳 ตัดชำระ] ระบบจะสลับไปยังแท็บรับเงินพร้อมกรอกข้อมูลลูกหนี้ให้อัตโนมัติทันที
