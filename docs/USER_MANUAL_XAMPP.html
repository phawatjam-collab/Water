1. ข้อกำหนดคุณสมบัติของระบบและสภาพแวดล้อมการทำงาน (System Specifications)
ฝั่งเครื่องแม่ข่าย (Server Environment):
• ระบบปฏิบัติการ: Windows 10/11 (64-bit) หรือ Linux Ubuntu LTS
• หน่วยประมวลผล: Intel Core i3 / AMD Ryzen 3 ขึ้นไป (2.0 GHz+)
• หน่วยความจำ (RAM): 4 GB ขึ้นไป (แนะนำ 8 GB เพื่อความรวดเร็ว)
• พื้นที่จัดเก็บข้อมูล: ขั้นต่ำ 500 MB สำหรับระบบและฐานข้อมูล
• สภาพแวดล้อมเซิร์ฟเวอร์: XAMPP สำหรับ Windows (PHP 8.0-8.2, Apache 2.4, MariaDB 10.4)
ฝั่งเครื่องลูกข่ายและอุปกรณ์ผู้ใช้ (Client Devices):
• คอมพิวเตอร์สำนักงาน: รองรับการเปิดผ่านเว็บเบราว์เซอร์ Google Chrome, Microsoft Edge, Mozilla Firefox รุ่นปัจจุบัน
• สมาร์ตโฟน / แท็บเล็ต: Android 9+ หรือ iOS 13+ พร้อมกล้องหลังสำหรับสแกน QR Code หน้าบ้าน
• เครื่องพิมพ์: เครื่องพิมพ์เลเซอร์หรืออิงก์เจ็ตมาตรฐาน A4 สำหรับพิมพ์ใบเสร็จ ป.31/32, สติกเกอร์ QR และงบดุล

3. ขั้นตอนการติดตั้งและเริ่มต้นระบบบน XAMPP (Installation & Setup)
ขั้นตอนที่ 1: การวางตำแหน่งไฟล์ระบบ
นำโฟลเดอร์โครงการไปวางไว้ในไดเรกทอรีเว็บเซิร์ฟเวอร์ของ XAMPP ที่ C:\xampp\htdocs\plumber หรือ D:\Games\xamppp\htdocs\plumber ตามโครงสร้างการติดตั้งในเครื่องของท่าน
ขั้นตอนที่ 2: การเริ่มทำงานของ Apache และ MySQL
เปิดโปรแกรม XAMPP Control Panel จากนั้นกดปุ่ม [Start] ที่โมดูล Apache (พอร์ต 80, 443) และ MySQL (พอร์ต 3306) ให้ทั้งสองแถบเปลี่ยนเป็นสถานะสีเขียว
ขั้นตอนที่ 3: การเริ่มต้นฐานข้อมูลอัตโนมัติ (Zero-Config Database Setup)
เปิดเว็บเบราว์เซอร์แล้วเข้าสู่ระบบที่ http://localhost/plumber/ ระบบจะทำการตรวจสอบฐานข้อมูล db_city_water_supply อัตโนมัติ หากยังไม่มี ระบบจะสร้างฐานข้อมูลและนำเข้าข้อมูล 400 ครัวเรือนจากไฟล์ database.sql ให้ทันทีโดยที่ผู้ใช้ไม่ต้องเปิด phpMyAdmin

5. ขั้นตอนการปฏิบัติงานประจำงวด: การจดบันทึกมาตรวัดน้ำ (แบบ ป.17)
ขั้นตอนที่ 1: การเตรียมการและการพิมพ์สติกเกอร์ QR Code ติดหน้าบ้าน
1. เจ้าหน้าที่เข้าสู่เมนูพิมพ์สติกเกอร์ที่ print_qr_labels.php
2. เลือกรอบบิลและโซนที่ต้องการจัดพิมพ์ ระบบจะจัดวางแผ่นป้าย QR Code พร้อมบ้านเลขที่และรหัสประจำตัว (WY-xxx) ในขนาดมาตรฐาน A4 (มีรูปแบบ 12 ป้าย/แผ่น และ 24 ป้าย/แผ่น)
3. สั่งพิมพ์ลงบนกระดาษสติกเกอร์กันน้ำเพื่อนำไปติดที่ฝาครอบมาตรวัดน้ำของแต่ละบ้าน
ขั้นตอนที่ 2: การเดินจดบันทึกมาตรวัดน้ำภาคสนาม (meter_reading.php)
1. ช่างเปิดสมาร์ตโฟนเชื่อมต่อระบบ แล้วเข้าสู่หน้า meter_reading.php
2. เลือกรอบเดือนที่กำลังจด (เช่น 8-2567) ระบบจะดึงรายชื่อผู้ใช้น้ำเรียงลำดับตามเส้นทางเดินจริง (seq_no) ตั้งแต่คุ้มเหนือจรดคุ้มใต้
3. การบันทึกทำได้ 2 รูปแบบ:
  • รูปแบบสแกนกล้อง: กดปุ่ม [📷 สแกน QR] ส่องกล้องมือถือไปที่สติกเกอร์หน้าบ้าน ระบบจะกระโดดไปยังแถวของบ้านหลังนั้นทันที
  • รูปแบบค้นหาด้วยเบอร์/บ้านเลขที่: พิมพ์บ้านเลขที่ลงในช่องค้นหาด่วน
ขั้นตอนที่ 3: การป้อนเลขอ่านและระบบตรวจจับค่าผิดปกติ (Anomaly Detection)
1. ป้อนตัวเลขอ่านครั้งนี้ (Current Reading) ในช่องรับข้อมูล ระบบจะคำนวณจำนวนหน่วยที่ใช้สดทันทีตามสูตร: หน่วย = เลขครั้งนี้ - เลขครั้งก่อน
2. การแจ้งเตือนค่าผิดปกติ:
  • กรณีเลขถอยหลัง (Current < Previous): ระบบจะแสดงข้อความเตือนแถบสีแดงและไม่อนุญาตให้บันทึก เพื่อป้องกันข้อผิดพลาดในการจดสลับหลัก
  • กรณีใช้น้ำพุ่งสูงเกิน 3 เท่า: ระบบจะแสดงข้อความเตือนให้ตรวจสอบว่ามีจุดท่อแตกภายในบ้านหรือไม่
3. กดปุ่ม [บันทึก] ข้อมูลจะถูกจัดเก็บเข้าตาราง meter_readings ทันที และแถบ Progress Bar ด้านบนจะขยับเพิ่มขึ้นตามความคืบหน้า

8. การสำรองข้อมูลและการแก้ปัญหาเบื้องต้น (Maintenance & Troubleshooting)
การสำรองฐานข้อมูลฉุกเฉิน (1-Click Database Backup):
ผู้ดูแลระบบสามารถเข้าสู่ระบบแล้วกดลิงก์ http://localhost/plumber/api/backup.php ระบบจะส่งออกไฟล์สำรองฐานข้อมูลโครงสร้างและข้อมูลทั้งหมดในรูปแบบ .sql ให้ดาวน์โหลดทันที ควรกดสำรองข้อมูลอย่างน้อยสัปดาห์ละ 1 ครั้ง และคัดลอกไฟล์เก็บไว้ในแฟลชไดรฟ์ภายนอก
ตารางการแก้ไขปัญหาที่พบบ่อย (Troubleshooting Guide)
ปัญหาที่พบ (Issue) สาเหตุที่เป็นไปได้ แนวทางการแก้ไข
Apache สตาร์ตไม่ติด
(แถบขึ้นสีแดง)		 พอร์ต 80 หรือ 443 ชนกับโปรแกรมอื่น เช่น Skype หรือ IIS เปิด Config ใน XAMPP เปลี่ยนพอร์ตใน httpd.conf เป็น 8080 หรือปิด Service ของโปรแกรมอื่น
MySQL สตาร์ตไม่ติด พอร์ต 3306 ชน หรือมี MySQL ตัวอื่นรันอยู่ เปิด Task Manager ยุติโปรแกรม mysqld.exe แล้วกด Start ใหม่อีกครั้ง
เปิดเว็บแล้วฟ้องว่า Database Connection Failed ไม่ได้เปิด MySQL หรือรหัสผ่าน root ไม่ตรงกับค่าเริ่มต้น ตรวจสอบว่าแถบ MySQL ใน XAMPP เป็นสีเขียว และตรวจสอบไฟล์ api/db.php ว่ารหัสผ่านเป็นค่าว่าง ""
กล้องมือถือไม่ยอมเปิดสแกน QR Code ยังไม่ได้ให้สิทธิ์เข้าถึงกล้อง (Permission) หรือไม่ได้ใช้งานผ่าน HTTPS กดอนุญาตให้เว็บเข้าถึงกล้องในเบราว์เซอร์ หรือใช้วิธีพิมพ์บ้านเลขที่ค้นหาแทน
