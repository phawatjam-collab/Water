# คู่มือการใช้งานและทดสอบต้นแบบส่วนติดต่อผู้ใช้บนโปรแกรม Axure RP
## โครงการระบบบริหารจัดการน้ำประปาหมู่บ้านวังยาง (Smart Village Waterworks Management System)

**หน่วยงานผู้ใช้งาน:** กองทุนระบบการประปาหมู่บ้านวังยาง หมู่ที่ 3 ตำบลวังยาง อำเภอวังยาง จังหวัดนครพนม  
**รหัสเอกสาร:** MN-2567-WTR-AXURE | **เวอร์ชัน:** 1.0 (ฉบับทดสอบต้นแบบ)  
**ไฟล์ต้นแบบจำลองภาพ (Axure RP Prototype):** `Plumber_ver-1003-gu-tam-kon-dew-i-sus.rp` (31 หน้าจอ)  
**ซอร์สโค้ด:** `https://github.com/phawatjam-collab/Water`  

---

## 1. ข้อมูลทั่วไปของไฟล์ต้นแบบ (Prototype Profile)
- **ชื่อไฟล์:** `Plumber_ver-1003-gu-tam-kon-dew-i-sus.rp`
- **โปรแกรมที่ใช้:** Axure RP 9 หรือ Axure RP 10
- **จำนวนหน้าจอ:** 31 หน้าจอ ครอบคลุม 4 กลุ่มงาน (บริการประชาชน, จดมิเตอร์, การเงินและใบเสร็จ, ผู้บริหารและงบดุล)
- **การเปิดทดสอบ:** สามารถพรีวิวผ่าน Axure RP หรือเปิดผ่านเว็บเบราว์เซอร์ผ่านไฟล์ HTML

---

## 2. ขั้นตอนการเปิดใช้งานและทดสอบต้นแบบ (How to Run & Preview)
1. **ผ่านโปรแกรม Axure RP:** เปิดไฟล์ `.rp` แล้วกดปุ่ม `[Ctrl + F5]` หรือคลิกเมนู **Publish $\rightarrow$ Preview**
2. **ผ่านเว็บเบราว์เซอร์:** เลือกเมนู **Publish $\rightarrow$ Generate HTML Files...** แล้วดับเบิลคลิกเปิดไฟล์ `index.html` หรือ `start.html` บนเบราว์เซอร์เครื่องใดก็ได้โดยไม่ต้องมีโปรแกรม Axure

---

## 3. แผนผังเส้นทางการทดสอบ 3 กลุ่มผู้ใช้งานหลัก (Test Journeys)

### เส้นทางที่ 1: บริการประชาชนผู้ใช้น้ำ (Citizen Journey Flow)
1. **ค้นหาค่าน้ำ (Screen 1):** พิมพ์เบอร์โทรศัพท์ตัวอย่าง `0812345678` หรือบ้านเลขที่ `45/1` กดค้นหา ระบบแสดงยอดเงิน 115.00 บาท
2. **เปิด QR พร้อมเพย์ (Screen 3):** กดปุ่มชำระเงิน ระบบแสดงภาพ QR Code พร้อมเพย์ตามมาตรฐาน EMVCo ตรงตามยอดสตางค์จริง
3. **แจ้งเหตุน้ำรั่ว (Screen 4):** กรอกชื่อ เบอร์โทร และรายละเอียดจุดเกิดเหตุ กดส่งเรื่อง ระบบสร้างรหัสติดตามงานซ่อม

### เส้นทางที่ 2: ช่างจดบันทึกมาตรวัดน้ำภาคสนาม (Field Reader Flow)
1. **ตารางเดินจดมิเตอร์ ป.17 (Screen 5):** เลือกรอบเดือน 8-2567 รายชื่อจะเรียงตามลำดับเส้นทางจริง (`seq_no`) พร้อมแถบ Progress Bar 88%
2. **จำลองสแกนกล้อง (Screen 6):** กดปุ่มสแกน QR Code หน้าบ้าน ระบบจะโฟกัสแถวข้อมูลให้อัตโนมัติ
3. **ทดสอบตรวจจับค่าผิดปกติ (Screen 6):** 
   - ลองป้อนเลขถอยหลัง (Current < Previous) ระบบจะขึ้นแถบเตือนสีแดง
   - ป้อนเลขปกติ ระบบคำนวณหน่วยใช้และค่าน้ำ 7+10 บ. ให้ทันที

### เส้นทางที่ 3: งานการเงิน ใบเสร็จ และงบดุล (Treasurer & Finance Flow)
1. **ตัดรับเงินและใบเสร็จ ป.31/32 (Screen 7 – 8):** กดปุ่ม `[รับชำระ]` สถานะเปลี่ยนเป็น PAID ทันที และกดปุ่ม `[ใบเสร็จ]` เพื่อเปิดป๊อปอัปใบเสร็จ ป.31/32 พร้อมตัวอักษรบาทไทย
2. **คุมหนี้ กค.4 (Screen 11 – 12):** กรองอายุหนี้เกิน 3 เดือน และกดพิมพ์หนังสือเตือน 7 วัน
3. **ฎีกาเบิกจ่ายค่าตอบแทน 10% (Screen 9):** กดปุ่ม `[ซิงค์ค่าตอบแทน 10%]` ระบบคำนวณเงิน 10% จากยอดที่จ่ายแล้วทั้งหมดอัตโนมัติ
4. **งบดุลประจำเดือน (Screen 18):** แสดงรายรับจริง รายจ่าย ยอดคงเหลือ บัญชีเงินสด/ธนาคาร และจุดลงนามกรรมการ 3 ท่าน

|:---:|:---|:---|:---|
