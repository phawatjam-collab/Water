## 1. บทนำและข้อกำหนดทางเทคนิค (Introduction & System Requirements)

### 1.1 ความต้องการของระบบฝั่งแม่ข่าย (Server Requirements)
- **ระบบปฏิบัติการ:** Windows 10/11 (64-bit), Windows Server หรือ Linux Ubuntu 22.04 LTS
- **หน่วยประมวลผล (CPU):** Intel Core i3 / AMD Ryzen 3 หรือสูงกว่า (ความเร็ว 2.0 GHz ขึ้นไป)
- **หน่วยความจำหลัก (RAM):** ขั้นต่ำ 4 GB (แนะนำ 8 GB เพื่อความรวดเร็วในการรองรับหลายอุปกรณ์)
- **พื้นที่จัดเก็บข้อมูล (Storage):** พื้นที่ว่างอย่างน้อย 2 GB (สำหรับฐานข้อมูลและเอกสารใบเสร็จ)
- **ซอฟต์แวร์สแต็ก:** 
  - XAMPP for Windows เวอร์ชัน 8.0.x, 8.1.x หรือ 8.2.x (ดาวน์โหลดได้ฟรีจาก apachefriends.org)
  - Apache HTTP Server 2.4.x
  - PHP 8.x พร้อมเปิดใช้งาน Extension: `pdo_mysql`, `mbstring`, `gd`, `openssl`
  - MariaDB 10.4.x หรือ MySQL 8.0.x (InnoDB Storage Engine)

### 1.2 ความต้องการของระบบฝั่งลูกข่าย (Client Requirements)
- **อุปกรณ์:** คอมพิวเตอร์ตั้งโต๊ะ, โน้ตบุ๊ก, แท็บเล็ต, หรือสมาร์ตโฟน (Android / iOS)
- **เว็บบราวเซอร์:** Google Chrome (แนะนำ), Microsoft Edge, Safari, Firefox เวอร์ชันปัจจุบัน
- **ความละเอียดหน้าจอ:** รองรับ Responsive ตั้งแต่ 360x640 พิกเซล (มือถือ) จนถึง 1920x1080 พิกเซล (เดสก์ท็อป)
- **อุปกรณ์เสริม (ถ้ามี):** กล้องมือถือสำหรับสแกน QR Code หน้าบ้าน, เครื่องพิมพ์ A4 สำหรับพิมพ์ใบเสร็จ ป.31/32

## 2. ขั้นตอนการติดตั้งและการเริ่มต้นระบบ (Installation & Zero-Config Setup)

### 2.1 การติดตั้งผ่านโปรแกรม XAMPP (เพียง 3 ขั้นตอน)
1. **คัดลอกโฟลเดอร์โครงการ:**  
   นำโฟลเดอร์โปรเจกต์ `plumber` ไปวางไว้ในไดเรกทอรี `htdocs` ของโปรแกรม XAMPP  
   *(เส้นทาง: `D:\Games\xamppp\htdocs\plumber` หรือ `C:\xampp\htdocs\plumber`)*
2. **เริ่มต้นบริการเซิร์ฟเวอร์:**  
   เปิดโปรแกรม **XAMPP Control Panel** และกดปุ่ม **Start** ที่โมดูล **Apache** และ **MySQL** (ทั้งสองโมดูลต้องเปลี่ยนเป็นสถานะสีเขียว)
3. **เปิดใช้งานระบบบนเบราว์เซอร์:**  
   เปิดเว็บบราวเซอร์และพิมพ์ URL:  
   `http://localhost/plumber/index.php`

### 2.2 สถาปัตยกรรมสร้างฐานข้อมูลอัตโนมัติ (Zero-Config DB Auto-Bootstrap)
> **💡 หมายเหตุสำคัญสำหรับผู้ดูแลระบบ:**  
> ระบบนี้ถูกออกแบบมาเพื่อชุมชนโดยเฉพาะ **ผู้ดูแลระบบไม่จำเป็นต้องเข้าไปสร้างฐานข้อมูลใน phpMyAdmin ด้วยตนเอง** เมื่อเปิดเข้าหน้าเว็บครั้งแรก ไฟล์ `api/db.php` จะทำหน้าที่:
> 1. ตรวจสอบว่ามีฐานข้อมูล `db_city_water_supply` อยู่ในระบบแล้วหรือไม่
> 2. หากยังไม่มี ระบบจะดำเนินการคำสั่ง `CREATE DATABASE IF NOT EXISTS db_city_water_supply` อัตโนมัติ
> 3. นำเข้าตารางและข้อมูลสมาชิกตั้งต้น 400 ครัวเรือนจากไฟล์ `database.sql` เข้าสู่ฐานข้อมูลให้ทันทีใน 2 วินาที

### 2.3 การตั้งค่า IP Address และการเชื่อมต่อผ่าน Wi-Fi ภายในสำนักงาน
เพื่อให้เจ้าหน้าที่ใช้สมาร์ตโฟนเชื่อมต่อระบบในสำนักงานประปาหมู่บ้านได้:
1. เปิด Command Prompt บนเครื่อง Server แล้วพิมพ์คำสั่ง `ipconfig` เพื่อดู IPv4 Address (เช่น `192.168.1.100`)
2. นำสมาร์ตโฟนของเจ้าหน้าที่เชื่อมต่อกับ Wi-Fi Router เดียวกันกับเครื่อง Server
3. เปิดเบราว์เซอร์บนมือถือ แล้วพิมพ์: `http://192.168.1.100/plumber/`

## 4. คู่มือการใช้งานระบบจริงแยกตามโมดูล (Step-by-Step Module Guide)

### 4.1 โมดูลบริการประชาชนและการตรวจสอบค่าน้ำ (`index.php`)
- **วัตถุประสงค์:** ช่องทางสาธารณะสำหรับประชาชนตรวจสอบยอดค่าน้ำและชำระเงินออนไลน์
- **ขั้นตอนการใช้งาน:**
  1. เข้าสู่หน้าหลัก `http://localhost/plumber/index.php`
  2. สังเกตการ์ดสรุปสถิติกองทุน 4 ตัวด้านบน (ผู้ใช้น้ำทั้งหมด, ปริมาณน้ำรวม, อัตราค่าน้ำ 7.00 บ., รายรับรวม)
  3. ในช่อง **"ตรวจสอบยอดค่าน้ำประปาของท่าน"** ให้พิมพ์ **หมายเลขโทรศัพท์ 10 หลัก** (เช่น `0812345678`) หรือบ้านเลขที่
  4. กดปุ่ม **[🔍 ค้นหาค่าน้ำ]** หรือกด Enter:
     - ระบบจะแสดงการ์ดข้อมูลผู้ใช้น้ำ: ชื่อ-สกุล, บ้านเลขที่, มิเตอร์เลขที่, ปริมาณน้ำที่ใช้, และยอดเงินสุทธิ
     - มีปุ่ม **[📱 ชำระเงินด้วย QR Code พร้อมเพย์]**: เมื่อคลิกจะแสดงภาพ QR Code พร้อมเพย์มาตรฐาน EMVCo ตรงตามยอดสตางค์จริงสำหรับเปิดแอปธนาคารสแกนจ่ายได้ทันที
  5. ด้านล่างมีแบบฟอร์ม **"แจ้งเหตุท่อแตก / น้ำประปาไม่ไหล"** สำหรับส่งเรื่องแจ้งซ่อมพร้อมระบุพิกัด

### 4.2 โมดูลเดินจดบันทึกเลขอ่านมิเตอร์น้ำภาคสนาม (`meter_reading.php`)
- **วัตถุประสงค์:** สำหรับเจ้าหน้าที่เดินจดมิเตอร์ผ่านสมาร์ตโฟน จัดเรียงตามลำดับหน้าบ้านจริง (แบบ ป.17)
- **ขั้นตอนการใช้งาน:**
  1. เข้าสู่ระบบด้วยบทบาท **Staff** แล้วเลือกเมนู **"จดมิเตอร์น้ำ"**
  2. เลือก **"งวดเดือน"** ที่ต้องการจด (เช่น `8-2567`)
  3. ตารางจะแสดงรายชื่อผู้ใช้น้ำเรียงตามลำดับเส้นทางเดินจด (`seq_no`) จากบ้านแรกไปบ้านสุดท้าย
  4. การบันทึกเลขอ่านทำได้ 2 วิธี:
     - **วิธีที่ 1 (สแกน QR Code หน้าบ้าน):** กดปุ่ม **[📷 สแกน QR]** ระบบจะเปิดกล้องมือถือเพื่อสแกนสติกเกอร์ที่ติดบนมิเตอร์น้ำ และเลื่อนเคอร์เซอร์ไปยังแถวของบ้านหลังนั้นโดยอัตโนมัติ
     - **วิธีที่ 2 (พิมพ์ตัวเลขโดยตรง):** คลิกที่ช่อง **"เลขครั้งนี้"** ของผู้ใช้น้ำ แล้วพิมพ์ตัวเลขมิเตอร์ที่อ่านได้
  5. **การทำงานอัตโนมัติของระบบ:**
     - ระบบจะคำนวณ: `หน่วยที่ใช้ = เลขครั้งนี้ - เลขครั้งก่อน`
     - คำนวณยอดเงิน: `(หน่วยใช้ x 7 บาท) + ค่าบำรุง 10 บาท + หนี้ค้างเก่า = ยอดสุทธิ`
     - บันทึกข้อมูลลงฐานข้อมูลแบบ Auto-Save ทันที
     - อัปเดตแถบ **"ความคืบหน้าการจดมิเตอร์"** (เช่น 88%) ด้านบนสดๆ
  6. **ระบบตรวจจับความผิดปกติ (Anomaly Protection):**
     - หากพิมพ์ตัวเลขครั้งนี้น้อยกว่าครั้งก่อน (`current < previous`) ระบบจะขึ้นแถบสีแดงแจ้งเตือนทันทีเพื่อป้องกันการพิมพ์ผิดหรือมิเตอร์หมุนกลับ

### 4.3 โมดูลระบบการเงิน ตัดรับชำระ และใบเสร็จ ป.31/32 (`finance_billing.php`)
- **วัตถุประสงค์:** ศูนย์กลางการเงินของเหรัญญิก รวม 4 ระบบงานไว้ในหน้าจอเดียว (Unified Control Header)
- **แท็บ 1: รายการตัดรับชำระเงิน (`#pane-collection`):**
  1. เลือกรอบเดือนที่แถบด้านบน
  2. ใช้ช่องค้นหาพิมพ์เบอร์โทรศัพท์หรือชื่อผู้ใช้น้ำเพื่อค้นหารายการ
  3. เมื่อได้รับเงินสดหรือการโอนเงิน ให้กดปุ่ม **[✅ รับชำระ]**:
     - สถานะจะเปลี่ยนเป็น **PAID (ชำระแล้ว)** สีเขียวทันทีแบบ Optimistic UI
     - ระบบออกเลขที่ใบเสร็จ `RC-YYYYMM-XXX` อัตโนมัติ
     - แสดง Toast แจ้งเตือนสีเขียวพร้อมปุ่มทางลัด **[🖨️ พิมพ์ใบเสร็จ]**
  4. หากต้องการดูใบเสร็จทันที ให้กดปุ่ม **[🧾 ใบเสร็จ]**:
     - หน้าต่าง **Quick Receipt Modal** จะป๊อปอัปขึ้นมาทันทีโดยไม่ต้องสลับหน้า
     - แสดงฟอร์มใบเสร็จรับเงินแบบ ป.31/32 พร้อมตัวเลขแปลงเป็นบาทไทย
     - กดปุ่ม **[🖨️ พิมพ์ใบเสร็จรับเงิน]** เพื่อสั่งพิมพ์ลงกระดาษ A4 หรือ A5 ได้ทันที
  5. หากต้องการดาวน์โหลดบัญชีค่าน้ำประจำงวด ให้กดปุ่ม **[📥 ส่งออก Excel]**

- **แท็บ 2: พิมพ์ใบเสร็จรับเงินเต็มรูปแบบ (`#pane-receipt`):**
  - ใช้สำหรับเลือกดูและพิมพ์ใบเสร็จรับเงิน ป.31/32 รายบุคคลแบบเต็มหน้าจอ พร้อมช่องลงนามเหรัญญิกและประธาน

### 4.4 โมดูลทะเบียนคุมหนี้ค้างชำระ กค.4 และหนังสือเตือน (`finance_billing.php` - Tab 3)
- **วัตถุประสงค์:** จัดการและติดตามผู้ใช้น้ำที่ค้างชำระเงินตามระเบียบแบบ กค.4
- **ขั้นตอนการใช้งาน:**
  1. คลิกที่แท็บ **"3. ทะเบียนคุมหนี้ค้างชำระ (กค.4)"**
  2. เลือกระดับความเร่งด่วนตามอายุหนี้:
     - 🟡 **ค้างชำระ 1 งวด:** หนี้เตือนเบื้องต้น
     - 🟠 **ค้างชำระ 2 งวด:** หนี้เตือนเร่งด่วน
     - 🔴 **ค้างชำระ 3 งวดขึ้นไป:** หนี้วิกฤต (เตรียมระงับการจ่ายน้ำ)
  3. ตารางจะแสดงยอดหนี้สะสมรวมของลูกหนี้แต่ละราย
  4. การดำเนินการ:
     - **กดปุ่ม [✉️ ออกหนังสือเตือน]:** ระบบจะเปิดเอกสาร **"หนังสือเตือนระงับการใช้น้ำชั่วคราว"** ดึงยอดหนี้รวมและกำหนดเส้นตายชำระภายใน 7 วัน พร้อมสั่งพิมพ์เพื่อนำไปส่งที่บ้านลูกหนี้
     - **กดปุ่ม [💳 ตัดชำระ]:** ระบบจะสลับหน้าจอกลับไปยังแท็บ 1 ทันที พร้อมกรอกชื่อลูกหนี้ลงช่องค้นหาให้อัตโนมัติ เพื่อรับเงินได้ทันทีโดยไม่ต้องพิมพ์ใหม่

### 4.5 โมดูลฎีกาเบิกจ่ายและค่าตอบแทนผู้จัดเก็บ 10% (`finance_billing.php` - Tab 4)
- **วัตถุประสงค์:** ออกใบสำคัญรับเงินและฎีกาเบิกจ่ายเงินกองทุนประปาตามระเบียบกระทรวงมหาดไทย
- **ขั้นตอนการใช้งาน:**
  1. คลิกที่แท็บ **"4. ฎีกาเบิกจ่ายเงิน (10% & ค่าใช้จ่าย)"**
  2. สังเกตการ์ดสรุปยอดเงิน 3 ใบด้านบน:
     - **ยอดรับชำระแล้ว:** แสดงยอดเงินสดที่เก็บได้จริงในงวดนั้น
     - **ยอดค้างชำระ:** แสดงยอดหนี้ที่ยังเก็บไม่ได้
     - **ยอดจัดเก็บรวม:** ยอดเรียกเก็บทั้งหมด
  3. **การออกฎีกาค่าตอบแทนผู้จัดเก็บ 10%:**
     - กดปุ่ม **[🔄 ซิงค์ค่าตอบแทน 10%]**
     - ระบบจะคำนวณ: `ยอดค่าตอบแทน = ยอดรับชำระจริง x 10%`
     - สร้างรายการฎีกาเบิกจ่ายให้อัตโนมัติ พร้อมระบุชื่อผู้จัดเก็บ และแปลงตัวเลขเป็นตัวอักษรบาทไทย
  4. **การออกฎีกาเบิกจ่ายหมวดอื่นๆ:**
     - กดปุ่ม **[➕ ออกฎีกาเบิกจ่ายรายการใหม่]**
     - เลือกหมวดค่าใช้จ่าย (ค่ากระแสไฟฟ้าเครื่องสูบน้ำ, ค่าซ่อมท่อแตก, ค่าสารส้ม/คลอรีน, ค่าเบี้ยประชุม)
     - กรอกจำนวนเงินและรายละเอียด
     - กดบันทึกเพื่อสร้างใบสำคัญรับเงินที่มีช่องลงนาม 3 ตำแหน่ง (ผู้รับเงิน, เหรัญญิก, ประธานกองทุน)

- **วัตถุประสงค์:** เครื่องมือสำหรับประธานกองทุนและคณะกรรมการบริหารประปาหมู่บ้าน

  - รายงานงบดุลประจำเดือน (Balance Sheet): สรุปรายรับสุทธิ หักรายจ่ายสุทธิ คงเหลือยกไป พร้อมจุดลงนามคณะกรรมการ 3 ท่าน

## 5. การบำรุงรักษาและการกู้คืนข้อมูลฉุกเฉิน (Disaster Recovery & Backup)

### 5.1 การสำรองฐานข้อมูลในคลิกเดียว (1-Click Database Backup)
เพื่อป้องกันข้อมูลทางการเงินสูญหายจากไฟดับ ไวรัส หรือความเสียหายของฮาร์ดดิสก์:
1. เข้าสู่ระบบด้วยบทบาท **Admin**
2. ไปที่เมนู **"สำรองฐานข้อมูล"** หรือเรียกผ่าน URL: `http://localhost/plumber/api/backup.php`
3. เบราว์เซอร์จะทำการดาวน์โหลดไฟล์สำรองข้อมูลอัตโนมัติในรูปแบบ:  
   `backup_city_water_YYYY-MM-DD_HH-ii-ss.sql`
4. แนะนำให้เหรัญญิกทำการคัดลอกไฟล์ `.sql` นี้ลงใน **Flash Drive หรือ External HDD** ทุกสิ้นเดือนหลังปิดงวดบัญชี

### 5.2 ขั้นตอนการกู้คืนฐานข้อมูล (Database Restore Procedure)
หากเกิดเหตุฉุกเฉินที่ต้องลงโปรแกรมใหม่บนคอมพิวเตอร์เครื่องอื่น:
1. ติดตั้ง XAMPP บนเครื่องใหม่
2. เปิดเบราว์เซอร์เข้า `http://localhost/phpmyadmin`
3. คลิกแท็บ **"นำเข้า (Import)"**
4. เลือกไฟล์ `.sql` ล่าสุดที่สำรองไว้ แล้วกด **"นำเข้า / Go"** ข้อมูลและประวัติการเงินทั้งหมดจะกลับมาสมบูรณ์ 100%

## 6. การแก้ไขปัญหาเบื้องต้น (Troubleshooting & FAQs)

| ปัญหาที่พบ | สาเหตุที่เป็นไปได้ | วิธีการแก้ไข |
|:---|:---|:---|
| **เปิดหน้าเว็บไม่ได้ (ขึ้น Cannot connect)** | ลืมสตาร์ต Apache ใน XAMPP | เปิด XAMPP Control Panel แล้วกดปุ่ม **Start** ที่โมดูล Apache |
| **ขึ้นข้อความ Database connection failed** | ลืมสตาร์ต MySQL ใน XAMPP | กดปุ่ม **Start** ที่โมดูล MySQL ใน XAMPP Control Panel |
| **เข้าผ่านมือถือในวง Wi-Fi ไม่ได้** | Firewall ของ Windows บล็อกพอร์ต 80 | ไปที่ Windows Defender Firewall เลือก Allow Apache HTTP Server ผ่านเครือข่าย Private |
| **จดเลขมิเตอร์แล้วขึ้นแถบสีแดง** | ตัวเลขครั้งนี้น้อยกว่าครั้งก่อน | ตรวจสอบว่าดูเลขมิเตอร์ผิดหรือไม่ หากมิเตอร์หมุนวนรอบใหม่ ให้ติดต่อผู้ดูแลระบบ |
| **สแกน QR Code หน้าบ้านไม่ได้** | แสงสว่างไม่เพียงพอ หรือกล้องไม่โฟกัส | ใช้ไฟฉายส่อง หรือพิมพ์ค้นหาด้วยบ้านเลขที่/เบอร์โทรศัพท์แทนได้ทันที |
