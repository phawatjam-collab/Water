# คู่มือการติดตั้งและใช้งานระบบจริงบนสภาพแวดล้อม XAMPP
## โครงการระบบบริหารจัดการน้ำประปาหมู่บ้านวังยาง (Smart Village Waterworks Management System)

**หน่วยงานผู้ใช้งาน:** กองทุนระบบการประปาหมู่บ้านวังยาง หมู่ที่ 3 ตำบลวังยาง อำเภอวังยาง จังหวัดนครพนม  
**รหัสเอกสาร:** MN-2567-WTR-XAMPP | **เวอร์ชัน:** 1.0 (ฉบับปฏิบัติงานจริง)  
**ซอร์สโค้ด:** `https://github.com/phawatjam-collab/Water`  

---

## 1. ข้อกำหนดคุณสมบัติของระบบ (System Specifications)
- **เครื่องแม่ข่าย (Server):** Windows 10/11 หรือ Linux, RAM ขั้นต่ำ 4 GB, พื้นที่ว่าง 500 MB, แพ็กเกจ XAMPP (Apache 2.4, PHP 8, MariaDB 10.4)
- **เครื่องลูกข่าย (Client):** คอมพิวเตอร์สำนักงาน, สมาร์ตโฟน Android/iOS พร้อมกล้องสำหรับสแกน QR Code หน้าบ้าน
- **เครื่องพิมพ์:** เลเซอร์หรืออิงก์เจ็ตมาตรฐาน A4 สำหรับพิมพ์ใบเสร็จ ป.31/32, สติกเกอร์ QR และงบดุล

---

## 2. ขั้นตอนการติดตั้งและเริ่มต้นระบบ (Installation Steps)
1. นำโฟลเดอร์โครงการไปวางไว้ที่ `htdocs/plumber` ของ XAMPP
2. เปิด **XAMPP Control Panel** และกดปุ่ม `[Start]` ที่โมดูล **Apache** และ **MySQL**
3. เปิดเว็บเบราว์เซอร์ไปที่ `http://localhost/plumber/` ระบบจะทำการตรวจสอบและนำเข้าฐานข้อมูล `database.sql` ให้โดยอัตโนมัติ (Zero-Config DB Setup)

---

## 3. การเข้าสู่ระบบและการทดสอบสิทธิ์ผู้ใช้ (User Accounts)
เข้าใช้งานผ่านหน้าล็อกอิน `http://localhost/plumber/auth.php`:
- **ผู้ดูแลระบบ (Superadmin):** `admin` / `admin123` (อนุมัติฎีกา, ดูงบดุล, แก้ไขอัตราค่าน้ำ, สำรองฐานข้อมูล)
- **เจ้าหน้าที่ (Staff):** `staff` / `staff123` (จดมิเตอร์ ป.17, ตัดรับเงิน, ออกใบเสร็จ ป.31/32, คุมหนี้ กค.4)
- **สมาชิกผู้ใช้น้ำ (Member):** `user001` / `pass123` (ดูกราฟย้อนหลัง, สแกน QR พร้อมเพย์, แจ้งท่อแตก)

## 4. ขั้นตอนการปฏิบัติงานประจำงวด (Monthly Operations Workflow)

### ขั้นตอนที่ 1: การพิมพ์สติกเกอร์ QR Code ติดหน้าบ้าน (print_qr_labels.php)
- เข้าเมนู `print_qr_labels.php` เลือกรอบบิลและโซน สั่งพิมพ์สติกเกอร์รหัส QR Code ขนาด 12 หรือ 24 ป้ายต่อแผ่น A4 นำไปติดที่ฝาครอบมาตรวัดน้ำของแต่ละบ้าน

### ขั้นตอนที่ 2: การจดบันทึกมาตรวัดน้ำภาคสนาม (meter_reading.php)
- ช่างเปิดหน้า `meter_reading.php` บนสมาร์ตโฟน รายชื่อจะเรียงตามลำดับเส้นทางเดินจริง (`seq_no`)
- กดปุ่มสแกน QR Code หน้าบ้าน หรือพิมพ์ค้นหาบ้านเลขที่
- ป้อนเลขอ่านครั้งนี้ ระบบคำนวณหน่วยน้ำสดทันที พร้อมแจ้งเตือนกรณีเลขถอยหลังหรือใช้น้ำพุ่งเกิน 3 เท่า

### ขั้นตอนที่ 3: การค้นหายอดค่าน้ำสำหรับประชาชน (index.php)
- ประชาชนพิมพ์หมายเลขโทรศัพท์ 10 หลัก หรือบ้านเลขที่ บนหน้าแรก ระบบค้นหาไม่เกิน 0.05 วินาที แสดงยอดและปุ่มเปิด QR Code พร้อมเพย์ตามยอดเงินจริง

### ขั้นตอนที่ 4: การรับชำระเงินและออกใบเสร็จ ป.31/32 (finance_billing.php - Tab 1)
- เจ้าหน้าที่กดปุ่ม `[รับชำระ]` สถานะเปลี่ยนเป็น PAID ทันที และกดปุ่ม `[ใบเสร็จ]` เพื่อเปิดหน้าต่างพิมพ์ใบเสร็จ ป.31/32 พร้อมตัวอักษรบาทไทย

### ขั้นตอนที่ 5: การควบคุมหนี้ค้างชำระ กค.4 (finance_billing.php - Tab 3)
- ตรวจสอบรายชื่อผู้ค้างชำระตามอายุหนี้ 1/2/3+ เดือน กดพิมพ์หนังสือเตือน 7 วัน หรือกดปุ่มตัดรับชำระเงินด่วน

### ขั้นตอนที่ 6: การเบิกจ่ายค่าตอบแทน 10% (finance_billing.php - Tab 4)
- กดปุ่ม `[ซิงค์ค่าตอบแทน 10%]` ระบบคำนวณเงินจากยอดรับชำระจริงในงวดคูณ 10% อัตโนมัติ พร้อมออกใบสำคัญเบิกจ่าย 8 หมวด

### ขั้นตอนที่ 7: รายงานงบดุลประจำเดือน (executive_reports.php)
- สรุปงบดุล รายรับ-รายจ่าย ยอดคงเหลือ บัญชีเงินสด/ธนาคาร และส่งออกตารางเป็นไฟล์ Excel ผ่าน `api/export_excel.php`

## 5. การสำรองข้อมูลและการแก้ปัญหา (Backup & Troubleshooting)
- **สำรองฐานข้อมูล:** เข้าลิงก์ `http://localhost/plumber/api/backup.php` ระบบจะดาวน์โหลดไฟล์ `.sql` ให้ทันที
- **Apache สตาร์ตไม่ติด:** พอร์ต 80 ชน ให้เปลี่ยนพอร์ตเป็น 8080 ใน `httpd.conf`
- **MySQL สตาร์ตไม่ติด:** ปิดโพรเซส `mysqld.exe` ใน Task Manager แล้วเปิดใหม่
