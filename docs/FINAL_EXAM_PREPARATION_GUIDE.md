## 1. การอธิบายระบบจากโครงงานกลุ่ม (10 คะแนน)
* **ชื่อระบบ:** ระบบบริหารจัดการการประปาหมู่บ้านวังยาง (Village Water Supply Management System)
* **สภาพปัญหาเดิม:** เจ้าหน้าที่ใช้สมุดกระดาษจดเลขมิเตอร์ (ป.17) ทำให้ตัวเลขคลาดเคลื่อนง่าย, คำนวณค่าน้ำและทบยอดหนี้ค้างชำระผิดพลาด, ประชาชนไม่ทราบยอดค่าน้ำล่วงหน้า, และการสรุปรายงานการเงินชุมชนล่าช้า
* **วัตถุประสงค์:**
  1. เพื่อเปลี่ยนระบบจดและคำนวณค่าน้ำประปาให้อยู่ในรูปแบบเว็บแอปพลิเคชัน ลดข้อผิดพลาดและทบยอดหนี้ค้างชำระอัตโนมัติ
  2. เพื่อพัฒนาระบบตรวจสอบค่าน้ำ แจ้งชำระเงิน และยื่นคำร้องแจ้งซ่อมท่อรั่วออนไลน์สำหรับประชาชน
  3. เพื่อจัดทำระบบรายงานสรุปงบการเงิน รายรับ-รายจ่าย รายการหนี้ค้างชำระ และอัตราน้ำสูญเสีย (NRW) ประจำเดือน

### ระดับสิทธิ์ 4 บทบาท (RBAC Architecture)
1. **Admin:** ควบคุมระบบทั้งหมด ตั้งค่าอัตราค่าน้ำต่อหน่วย ดูรายงานสรุปรายรับ-รายจ่าย และน้ำสูญเสีย
2. **Staff:** จดบันทึกเลขมิเตอร์ภาคสนาม ตัดรับชำระเงิน ออกใบเสร็จมาตรฐาน และจัดทำฎีกาเบิกจ่ายกองทุน
3. **Member:** เข้าสู่ระบบด้วยรหัสผู้ใช้น้ำ ดูประวัติการใช้น้ำย้อนหลัง พิมพ์ใบเสร็จ และสแกน QR Code ชำระเงิน
4. **Public:** ค้นหายอดค่าน้ำออนไลน์ตามบ้านเลขที่ และยื่นคำร้องแจ้งท่อแตก/น้ำไม่ไหล/ขอติดตั้งมิเตอร์

### ลำดับการทำงาน (Input $\rightarrow$ Process $\rightarrow$ Output)
* **โมดูลจดมิเตอร์และคำนวณค่าน้ำ:**
  * **Input:** รหัสรอบบิล, รหัสผู้ใช้น้ำ, เลขมิเตอร์ครั้งนี้ (`current_reading`)
  * **Process:** ตรวจสอบเลขใหม่ $\ge$ เลขเก่า $\rightarrow$ คำนวณหน่วยใช้ = เลขใหม่ − เลขเก่า $\rightarrow$ ค่าน้ำ = หน่วยใช้ $\times$ 7 บาท $\rightarrow$ ยอดสุทธิ = ค่าน้ำ + ค่าบริการ 10 บาท + หนี้ค้างชำระเดิม $\rightarrow$ บันทึกสถานะ `UNPAID`
  * **Output:** รายการบันทึกสถานะ `UNPAID`, ยอดรวมค่าน้ำสุทธิ, ใบแจ้งหนี้ค่าน้ำประจำงวด
* **โมดูลตัดรับชำระเงินและออกใบเสร็จ:**
  * **Input:** รหัสบิล, จำนวนเงินที่รับชำระ, ช่องทางชำระ (เงินสด / PromptPay)
  * **Process:** ตรวจสอบยอดเงิน $\rightarrow$ อัปเดตสถานะเป็น `PAID` $\rightarrow$ สร้างเลขที่ใบเสร็จ $\rightarrow$ แปลงยอดเงินเป็นตัวอักษรภาษาไทย (`bahtText`)
  * **Output:** ใบเสร็จรับเงินทางการพร้อมพิมพ์, ปรับลดยอดหนี้คงเหลือเป็น 0.00, อัปเดตรายงานการเงิน

### ส่วนงานที่ตนเองรับผิดชอบ
* *"ข้าพเจ้ารับผิดชอบการออกแบบฐานข้อมูลเชิงสัมพันธ์ (Database Schema) ตาราง `tb_customers`, `meter_readings`, `billing_cycles`, `tb_users` พร้อมกำหนด Primary Key, Foreign Key และ Referential Integrity รวมถึงเขียนคำสั่ง SQL และสคริปต์ PHP ฝั่งเซิร์ฟเวอร์ในการประมวลผลคำนวณค่าน้ำแบบอัตโนมัติ จัดการระบบความปลอดภัยและ Session"*

## 2. การเขียนคำสั่ง SQL (10 คะแนน — 5 ข้อย่อย)

### 2.1 การเลือกคอลัมน์และเปรียบเทียบตัวเลข
```sql
SELECT emp_id, emp_name, salary
FROM employees
WHERE salary > 35000;
```

### 2.2 การกำหนดหลายเงื่อนไขด้วย AND และ OR (ต้องใส่วงเล็บ)
```sql
SELECT emp_name, department, salary
FROM employees
WHERE (department = 'ไอที' OR department = 'การเงิน')
  AND salary >= 30000;
```

### 2.3 การคำนวณระยะเวลาหรืออายุงานจากปีที่โจทย์กำหนด
```sql
-- เทียบกับปีคงที่ 2024
SELECT emp_name, hire_date, (2024 - YEAR(hire_date)) AS work_years
FROM employees
WHERE (2024 - YEAR(hire_date)) > 5;

-- เทียบกับปีปัจจุบันของระบบ
SELECT emp_name, (YEAR(CURDATE()) - YEAR(hire_date)) AS work_years
FROM employees;
```

### 2.4 การกรองข้อมูลตามข้อความ (สถานที่และประเภทค่าใช้จ่าย)
```sql
SELECT *
FROM expenses
WHERE (exp_type = 'ค่าซ่อมบำรุง' OR exp_type = 'ค่าเดินทาง')
  AND location = 'เชียงใหม่';

-- หรือใช้ IN
SELECT *
FROM expenses
WHERE exp_type IN ('ค่าซ่อมบำรุง', 'ค่าเดินทาง')
  AND location = 'เชียงใหม่';
```

### 2.5 การอ่านโครงสร้างตารางและกรองเงื่อนไขผสม
```sql
SELECT exp_id, amount, location
FROM expenses
WHERE amount >= 5000
  AND location <> 'กรุงเทพ';
```

## 3. พีชคณิตเชิงสัมพันธ์ (Relational Algebra) (10 คะแนน — 8 ข้อย่อย)

| สัญลักษณ์ | การดำเนินการ | ความหมายสำคัญ | ตารางผลลัพธ์ |
| :---: | :--- | :--- | :--- |
| **$\sigma$** | **Selection** | เลือกเฉพาะ**แถว**ตามเงื่อนไข (คอลัมน์เท่าเดิม) | $\sigma_{Dept='IT'}(R) \rightarrow$ Alice (40k), Charlie (50k) |
| **$\pi$** | **Projection** | เลือกเฉพาะ**คอลัมน์** และ**ตัดแถวซ้ำออก** | $\pi_{Dept}(R) \rightarrow$ IT, HR (เหลือ 2 แถว) |
| **$\cup$** | **Union** | รวมข้อมูล 2 ตาราง ตัดตัวซ้ำ (ต้อง Union-Compatible) | $R \cup S \rightarrow$ Alice, Bob, Charlie, David |
| **$\cap$** | **Intersection** | เอาเฉพาะแถวที่ซ้ำกันทั้ง 2 ตาราง | $R \cap S \rightarrow$ Bob |
| **$-$** | **Difference** | เอาตัวตั้ง หักตัวหลังออก ($R - S \neq S - R$) | $R - S \rightarrow$ Alice, Charlie |
| **$\times$** | **Cartesian Product** | จับคู่ทุกแถว (แถว $= m \times n$, คอลัมน์ $= c_1 + c_2$) | $A \times B \rightarrow$ 4 แถว (1-X, 1-Y, 2-X, 2-Y) |
| **$\bowtie$** | **Join** | เชื่อมโยง 2 ตารางตามคีย์ที่ตรงกัน | $Emp \bowtie Dept \rightarrow$ แสดงพนักงานพร้อมชื่อแผนก |
| **$\div$** | **Division** | หาคนที่จับคู่กับ**ทุกค่า**ของอีกตาราง (FOR ALL) | $Takes \div Req \rightarrow$ นศ. ที่ลงครบทั้ง DB และ Net |
