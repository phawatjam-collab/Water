บทนำ (Introduction)
1.1 ความเป็นมาและความสำคัญของโครงงาน (Background & Significance)

ระบบประปาหมู่บ้านเป็นสาธารณูปโภคขั้นพื้นฐานที่มีความสำคัญยิ่งต่อสุขอนามัยและความเป็นอยู่ของประชาชนในชนบท กิจการประปาหมู่บ้านวังยาง หมู่ที่ 3 ตำบลวังยาง อำเภอวังยาง จังหวัดนครพนม ปัจจุบันมีครัวเรือนที่ใช้น้ำจำนวน 400 ครัวเรือน การดำเนินงานที่ผ่านมาคณะกรรมการบริหารกิจการประปาใช้ระบบการจดบันทึกด้วยมือลงในสมุดกระดาษ ซึ่งก่อให้เกิดปัญหาและความล่าช้าในการปฏิบัติงานหลายประการ ได้แก่ การจดเลขอ่านมาตรวัดน้ำผิดพลาด ปัญหาตัวเลขมาตรวัดน้ำย้อนกลับ การคำนวณค่าน้ำด้วยมือที่ใช้เวลานานและมีโอกาสผิดพลาด การติดตามหนี้ค้างชำระไม่เป็นระบบ และการจัดทำหลักฐานการเบิกจ่ายเงินค่าตอบแทนผู้จัดเก็บร้อยละ 10 ตามมติที่ประชุมกองทุนขาดความโปร่งใสและตรวจสอบย้อนหลังได้ยาก

จากสภาพปัญหาดังกล่าว คณะผู้จัดทำจึงได้พัฒนาระบบบริหารจัดการน้ำประปาหมู่บ้านอัจฉริยะขึ้น โดยประยุกต์ใช้เทคโนโลยีเว็บแอปพลิเคชันภาษา PHP ร่วมกับฐานข้อมูล MySQL และออกแบบส่วนติดต่อผู้ใช้ด้วยโปรแกรม Axure RP เพื่อเปลี่ยนผ่านกระบวนการทำงานสู่ระบบดิจิทัล ช่วยให้การจดบันทึกมาตรวัดน้ำ การออกบิล การรับชำระเงิน และการทำบัญชีเป็นไปอย่างถูกต้อง รวดเร็ว และตรวจสอบได้

1.2 วัตถุประสงค์ของโครงงาน (Project Objectives)

1. เพื่อพัฒนาระบบจดบันทึกเลขอ่านมาตรวัดน้ำภาคสนามผ่านสมาร์ตโฟนตามลำดับเส้นทางจริง พร้อมระบบตรวจจับค่าผิดปกติ
2. เพื่อพัฒนาระบบการออกใบแจ้งหนี้และใบเสร็จรับเงินมาตรฐาน (แบบ ป.31/32) พร้อมสร้าง QR Code ชำระเงินผ่านระบบพร้อมเพย์
3. เพื่อพัฒนาระบบทะเบียนคุมลูกหนี้ค้างชำระ (แบบ กค.4) และพิมพ์หนังสือแจ้งเตือนระงับการใช้น้ำได้อย่างมีประสิทธิภาพ
4. เพื่อพัฒนาระบบคำนวณและจัดทำใบสำคัญเบิกจ่ายเงินค่าตอบแทนผู้จัดเก็บร้อยละ 10 และรายงานสรุปงบดุลประจำเดือนของกองทุน

1.3 ขอบเขตของโครงงาน (Project Scope)

โครงงานนี้ครอบคลุมการใช้งานของผู้ใช้น้ำจำนวน 400 ครัวเรือนในพื้นที่หมู่ที่ 3 ตำบลวังยาง โดยมีขอบเขตการทำงาน 5 มิติหลัก ได้แก่: (1) งานทะเบียนผู้ใช้น้ำและการสร้างสติกเกอร์รหัส QR Code (2) งานเดินจดบันทึกมาตรวัดน้ำภาคสนาม (3) งานค้นหายอดค่าน้ำและบริการประชาชน (4) งานรับชำระเงิน ออกใบเสร็จรับเงิน และคุมลูกหนี้ และ (5) งานบัญชี การเบิกจ่ายเงินกองทุน และรายงานสำหรับผู้บริหาร

2.2 สภาพแวดล้อมด้านฮาร์ดแวร์และซอฟต์แวร์ (Operating Environment)

1. สภาพแวดล้อมฝั่งเครื่องแม่ข่าย (Server): เครื่องคอมพิวเตอร์สำนักงาน ติดตั้งระบบปฏิบัติการ Windows 10/11 (64-bit), CPU Intel Core i3 หรือ AMD Ryzen 3 ขึ้นไป, หน่วยความจำ RAM 4 GB ขึ้นไป และแพ็กเกจ XAMPP (Apache 2.4, PHP 8.0-8.2, MariaDB 10.4) หรือติดตั้งบนเซิร์ฟเวอร์คลาวด์เสมือน (Cloud VPS) พร้อมมาตรฐานความปลอดภัย SSL (HTTPS)

2. สภาพแวดล้อมฝั่งเครื่องลูกข่าย (Client): เครื่องคอมพิวเตอร์สำนักงานและอุปกรณ์สมาร์ตโฟน (Android/iOS) รองรับเว็บเบราว์เซอร์ Google Chrome, Microsoft Edge, Mozilla Firefox และกล้องสำหรับสแกน QR Code หน้าบ้าน

2.3 สถาปัตยกรรมระบบ 4 ระดับ (4-Tier Software Architecture)

• Tier 1 (Presentation): Responsive Web UI พัฒนาด้วย HTML5, CSS3, JavaScript และ Bootstrap 5
• Tier 2 (Application): ภาษา PHP 8 ดำเนินการประมวลผลตรรกะ คำนวณค่าน้ำ ตรวจจับค่าผิดปกติ และควบคุมสิทธิ์
• Tier 3 (Data Storage): MariaDB/MySQL (InnoDB Engine, utf8mb4) รองรับธุรกรรม ACID Transactions
• Tier 4 (Integration): การสร้างภาพพร้อมเพย์ QR Code (EMVCo), การสแกนผ่านกล้อง และการส่งออกไฟล์ Excel

2.4 ระบบติดตั้งฐานข้อมูลอัตโนมัติ (Zero-Configuration Database)

ไฟล์ api/db.php มีกลไกตรวจสอบความมีอยู่ของฐานข้อมูล db_city_water_supply หากไม่พบฐานข้อมูล ระบบจะสร้างและนำเข้าโครงสร้างตารางรวมทั้งข้อมูลจำลอง 400 ครัวเรือนจากไฟล์ database.sql ให้โดยอัตโนมัติ ช่วยลดความซับซ้อนในการติดตั้งและพร้อมใช้งานได้ทันที

3.1 FR-01: ระบบทะเบียนผู้ใช้น้ำและการจัดทำสติกเกอร์ QR Code (Customer Registry & QR Labeling)

คำอธิบาย: ระบบทำหน้าที่จัดเก็บและปรับปรุงข้อมูลสมาชิกผู้ใช้น้ำจำนวน 400 ครัวเรือน กำหนดลำดับเส้นทางเดินจด (seq_no) และจัดพิมพ์แผ่นสติกเกอร์รหัส QR Code ประจำตัวมาตรวัดน้ำเพื่อนำไปติดที่ฝาครอบมาตรวัดน้ำหน้าบ้าน
ข้อมูลนำเข้า: ชื่อ-สกุล, บ้านเลขที่, โซนจ่ายน้ำ, หมายเลขโทรศัพท์, เลขซีเรียลมิเตอร์, ลำดับเส้นทางเดินจด
ผลลัพธ์: สร้างรหัสผู้ใช้น้ำอัตโนมัติ (WY-xxx) และสร้างแผ่นพิมพ์สติกเกอร์ QR Code ขนาดมาตรฐาน A4 (มีรูปแบบ 12 ป้าย/แผ่น และ 24 ป้าย/แผ่น)
ไฟล์ระบบที่รับผิดชอบ: register.php, print_qr_labels.php, api/customers.php (ตาราง tb_customers)

3.2 FR-02: ระบบจดบันทึกเลขอ่านมาตรวัดน้ำภาคสนามตามลำดับเส้นทาง (Sequential Field Recording: ป.17)

คำอธิบาย: แสดงรายชื่อผู้ใช้น้ำเรียงตามเส้นทางเดินจริงในพื้นที่ ช่างสามารถบันทึกตัวเลขผ่านสมาร์ตโฟน สแกน QR Code หน้าบ้านด้วยกล้องเพื่อค้นหาบ้านได้ทันที และระบบคำนวณจำนวนหน่วยน้ำที่ใช้สด
ข้อมูลนำเข้า: รอบเดือน/ปี (เช่น 8-2567), รหัสผู้ใช้น้ำ, เลขอ่านมาตรวัดน้ำครั้งนี้ (Current Reading)
ผลลัพธ์: บันทึกหน่วยน้ำที่ใช้, ปรับปรุงแถบความคืบหน้างวด (Progress Bar เช่น 88%) และแสดงรายชื่อที่ยังไม่ได้จด
ไฟล์ระบบที่รับผิดชอบ: meter_reading.php, api/readings.php, api/cycles.php (ตาราง meter_readings)

3.3 FR-03: ระบบคำนวณค่าน้ำประปาและตรวจจับความผิดปกติอัตโนมัติ (Tariff & Anomaly Engine)

สูตรการคำนวณ: ยอดสุทธิ = (จำนวนหน่วยที่ใช้ x 7.00 บาท) + 10.00 บาท (ค่าบำรุงรักษา) + หนี้ค้างเก่า

ตารางที่ 5.1 พจนานุกรมตารางฐานข้อมูลหลักในระบบ
ชื่อตาราง / วิว คีย์หลัก / คีย์นอก (Keys) คำอธิบายและข้อมูลที่จัดเก็บ

billing_cycles PK: id | UK: cycle_code รอบบัญชีค่าน้ำประปาประจำเดือน (เช่น 8-2567), กำหนดวันจดและวันครบกำหนดชำระ

5.2 มาตรการด้านความมั่นคงปลอดภัยตามแนวทาง OWASP Top 10

1. การป้องกันการฉีดคำสั่ง SQL (SQL Injection): ซอร์สโค้ดภาษา PHP ทุกไฟล์ในไดเรกทอรี api/ ใช้คำสั่ง PDO Prepared Statements 100% พร้อมการผูกตัวแปรพารามิเตอร์อย่างรัดกุม ป้องกันการแทรกแซงคำสั่ง SQL โดยเด็ดขาด
2. การเข้ารหัสผ่าน (Password Security): รหัสผ่านของผู้ใช้งานทั้งหมดได้รับการเข้ารหัสทางเดียวด้วยอัลกอริทึม BCRYPT Hashing ป้องกันการรั่วไหลของรหัสผ่านแม้ฐานข้อมูลถูกเข้าถึงโดยมิชอบ
3. การตรวจสอบสิทธิ์การใช้งาน (Session Guard): ระบบมีฟังก์ชัน Gatekeeper ตรวจสอบสถานะการเข้าสู่ระบบและระดับสิทธิ์ (Role) ในทุกหน้าที่เกี่ยวกับธุรกรรมการเงิน
