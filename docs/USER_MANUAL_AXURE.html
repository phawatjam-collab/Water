2. ขั้นตอนการทดสอบและสาธิตสดทีละ Flow (Flow 1 - 3)

Axure Manual • ส่วนที่ 2
🎬 Flow 1: การค้นหายอดค่าน้ำประชาชนและการเปิด QR พร้อมเพย์ (Screen 1)
1. เปิดหน้าแรก Screen 1 (Home Search) บนเบราว์เซอร์
2. คลิกที่ช่อง [เบอร์โทรศัพท์/บ้านเลขที่] แล้วพิมพ์ 0812345678
3. กดปุ่ม [ค้นหาค่าน้ำ]:
    • วิดเจ็ตจะสลับ State แสดงการ์ดผลลัพธ์ของ นายวิชัย ใจดี (บ้านเลขที่ 123/1) ใช้น้ำ 15 หน่วย ยอดเงิน 115.00 บาท
4. คลิกปุ่ม [📱 ชำระเงินด้วย QR Code พร้อมเพย์]:
    • หน้าต่าง Lightbox Modal จะเด้งขึ้นมาตรงกลางจอ แสดงภาพ QR Code พร้อมเพย์ตรงตามยอด 115.00 บาท
🎬 Flow 2: การเดินจดมิเตอร์ ป.17 และตรวจจับความผิดปกติ (Screen 5)
1. เปิดหน้า Screen 5 (Meter Reading Form P.17)
2. สังเกตแถบด้านบน: งวดเดือนสิงหาคม 2567 และแถบความคืบหน้า 88%
3. คลิกที่ปุ่ม [📷 สแกน QR Code]: หน้าจอจะจำลองภาพกล้องเปิดพร้อมกรอบสีเขียวแสดงการสแกนสำเร็จ
4. ทดสอบคำนวณสด: คลิกช่องเลขครั้งนี้ของแถวที่ 1 เปลี่ยนเลขเป็น 135 → หน่วยใช้จะเปลี่ยนเป็น 15 และยอดเงินคำนวณเป็น 115.00 ทันที
5. ทดสอบ Anomaly: ลองพิมพ์เลข 110 (น้อยกว่าเลขเดิม 120) → ขอบช่องจะเปลี่ยนเป็นสีแดงพร้อมข้อความเตือนเลขถอยหลัง
🎬 Flow 3: การตัดรับชำระเงินและเปิดพรีวิวใบเสร็จ ป.31/32 (Screen 7)
1. เปิดหน้า Screen 7 (Collection Dashboard)
2. คลิกปุ่ม [✅ รับชำระ] ที่แถวของลูกหนี้: ป้ายสถานะจะสลับเป็น PAID (ชำระแล้ว) สีเขียวทันที
3. คลิกปุ่ม [🧾 ใบเสร็จ]: หน้าต่าง Quick Receipt Modal จะป๊อปอัปขึ้นมาทันที แสดงใบเสร็จ ป.31/32 พร้อมตัวเลขแปลงเป็นบาทไทย *"หนึ่งร้อยสิบห้าบาทถ้วน"* และปุ่มสั่งพิมพ์

2. ขั้นตอนการทดสอบและสาธิตสดทีละ Flow (Flow 4 - 7)

Axure Manual • ส่วนที่ 2 (ต่อ)
🎬 Flow 4: การคุมหนี้ กค.4 และหนังสือเตือน 7 วัน (Screen 7 - State 3)
1. ในหน้า Screen 7 คลิกแท็บ "3. ทะเบียนคุมหนี้ค้างชำระ (กค.4)"
2. คลิกตัวกรอง [ค้าง 3 เดือนขึ้นไป] เพื่อกรองเฉพาะลูกหนี้ขั้นวิกฤต
3. คลิกปุ่ม [✉️ ออกหนังสือเตือน]: ระบบจะเปิดเอกสารหนังสือเตือนระงับการจ่ายน้ำ ดึงยอดหนี้รวม 450 บาท และกำหนดชำระ 7 วัน
4. คลิกปุ่ม [💳 ตัดชำระ]: ระบบจะกระโดดกลับมาแท็บ 1 พร้อมเลือกชื่อลูกหนี้ลงช่องค้นหาให้อัตโนมัติ
🎬 Flow 5: การซิงค์และออกฎีกาเบิกจ่ายค่าตอบแทน 10% (Screen 9)
1. คลิกแท็บ "4. ฎีกาเบิกจ่ายเงิน (10% & ค่าใช้จ่าย)" (Screen 9)
2. คลิกปุ่ม [🔄 ซิงค์ค่าตอบแทน 10%]: ระบบจะคำนวณ 1,078.00 x 10% = 107.80 บาท และเพิ่มรายการฎีกาใหม่ให้อัตโนมัติ
3. คลิกปุ่ม [👁️ ดูฎีกาเบิกจ่าย]: แสดงฟอร์มใบสำคัญรับเงิน 10% พร้อมช่องลงนาม 3 ท่าน (ผู้รับเงิน, เหรัญญิก, ประธาน)
🎬 Flow 6: การดูรายงานงบดุลประจำเดือน (Screen 18)
1. เปิดหน้า Screen 18 (Financial Balance Sheet)
2. หน้าจอแสดงตารางงบดุล 2 ฝั่ง: ฝั่งซ้ายรายรับสีเขียว / ฝั่งขวารายจ่ายสีแดง และยอดคงเหลือยกไป พร้อมจุดลงนาม 3 ท่าน
🎬 Flow 7: การพิมพ์สติกเกอร์ QR Code ติดมิเตอร์ (Screen 30)
1. เปิดหน้า Screen 30 → คลิกเลือกรูปแบบ [สติกเกอร์มาตรฐาน 12 ดวง] → แสดงแผ่นลาเบลพร้อมพิมพ์ A4

3. เทคนิคตรรกะใน Axure และการจับคู่โค้ดจริง (Logic & Code Mapping)

Axure Manual • ส่วนที่ 3

🧠 เทคนิคการเขียน Dynamic Logic ใน Axure RP 10:

1. การใช้ Global Variables:
• Var_SearchPhone: จำลองการจำค่าเบอร์โทรที่พิมพ์
• Var_PaidStatus: สลับสถานะ UNPAID $\rightarrow$ PAID
• Var_BillTotal: ส่งผ่านยอดเงินข้ามหน้าจอไปยัง Modal
2. การใช้ Dynamic Panel States:
• ใช้ในหน้า finance_billing.php รวม 4 แท็บงาน
• คำสั่ง: Set Panel State to [State] with Slide Left 200ms
• ทำให้เปลี่ยนแท็บงานได้โดยไม่กระตุกเหมือน SPA จริง
