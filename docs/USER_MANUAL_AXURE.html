3. ขั้นตอนการเปิดใช้งานและพรีวิวต้นแบบ (How to Run & Preview)
วิธีที่ 1: การเปิดและพรีวิวผ่านโปรแกรม Axure RP (สำหรับผู้มีโปรแกรม)
1. ดับเบิลคลิกเปิดไฟล์ Plumber_ver-1003-gu-tam-kon-dew-i-sus.rp บนโปรแกรม Axure RP 9 หรือ 10
2. กดปุ่มลัด [Ctrl + F5] หรือคลิกเมนู Publish $\rightarrow$ Preview ที่แถบเครื่องมือด้านบน
3. โปรแกรมจะเปิดหน้าต่างเว็บเบราว์เซอร์อัตโนมัติ โดยมีแถบ Sitemap ทางด้านซ้ายให้เลือกสลับหน้าจอ และพื้นที่แสดงผลการจำลองที่สามารถคลิกพิมพ์โต้ตอบได้จริง
วิธีที่ 2: การส่งออกเป็นไฟล์ HTML เพื่อเปิดทดสอบบนเบราว์เซอร์ (สำหรับกรรมการและอาจารย์)
1. ภายในโปรแกรม Axure RP เลือกเมนู Publish $\rightarrow$ Generate HTML Files... (หรือกด F8)
2. กำหนดโฟลเดอร์ปลายทางที่ต้องการจัดเก็บไฟล์ HTML แล้วกดปุ่ม [Generate]
3. ดับเบิลคลิกที่ไฟล์ start.html หรือ index.html เพื่อเปิดทดสอบบนเว็บเบราว์เซอร์เครื่องใดก็ได้โดยไม่ต้องมีโปรแกรม Axure
