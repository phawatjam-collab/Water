ระบบบริหารจัดการน้ำประปาหมู่บ้านวังยาง
(Smart Village Waterworks Management System)

กองทุนระบบการประปาหมู่บ้านวังยาง หมู่ที่ 3 ตำบลวังยาง อำเภอวังยาง จังหวัดนครพนม
1. บทสรุปผู้บริหารและความเป็นมาของโครงงาน (Executive Summary)

กิจการประปาหมู่บ้านวังยางดูแลผู้ใช้น้ำจำนวน 400 ครัวเรือน เดิมใช้การบันทึกข้อมูลด้วยสมุดกระดาษ ทำให้เกิดปัญหาเลขอ่านมาตรวัดน้ำคลาดเคลื่อน เลขถอยหลัง การคำนวณค่าน้ำล่าช้า การติดตามหนี้ค้างชำระไม่เป็นระบบ และการจัดทำหลักฐานการเบิกจ่ายค่าตอบแทนผู้จัดเก็บร้อยละ 10 ขาดความคล่องตัว คณะผู้จัดทำจึงได้พัฒนาระบบสารสนเทศบนเว็บด้วยภาษา PHP ร่วมกับฐานข้อมูล MySQL เพื่อรองรับการจดมาตรวัดน้ำผ่านสมาร์ตโฟนตามลำดับเส้นทางจริง การออกใบแจ้งหนี้และใบเสร็จรับเงิน (แบบ ป.31/32) การสร้าง QR Code ชำระเงินผ่านพร้อมเพย์ และการควบคุมบัญชีลูกหนี้ (แบบ กค.4) อย่างครบวงจร

3. ข้อกำหนดความต้องการเชิงหน้าที่ของระบบ (Functional Requirements Matrix)

รหัส ชื่อฟังก์ชันงาน ข้อมูลนำเข้า (Inputs) การประมวลผลและผลลัพธ์ (Outputs) ไฟล์ระบบจริง (PHP)
FR-01 ทะเบียนผู้ใช้น้ำและสติกเกอร์ QR Code ชื่อ-สกุล, บ้านเลขที่, โซน, หมายเลขโทรศัพท์, ลำดับเส้นทาง สร้างรหัสผู้ใช้น้ำอัตโนมัติ (WY-xxx) และจัดพิมพ์สติกเกอร์ QR Code ติดหน้าบ้าน 4 รูปแบบ register.php

4. สถาปัตยกรรมระบบและการเชื่อมโยงภาพร่างต้นแบบ (Architecture & Prototype)
สถาปัตยกรรมซอฟต์แวร์ 4 ระดับ (Software Architecture Overview):
• ระดับส่วนติดต่อผู้ใช้ (Presentation Tier): ออกแบบในลักษณะ Responsive รองรับการเปิดบนโทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์สำนักงาน พัฒนาด้วย HTML5, CSS3, JavaScript และ Bootstrap 5
• ระดับประมวลผลตรรกะ (Application Tier): ภาษา PHP 8 ดำเนินการคำนวณค่าน้ำ ตรวจจับความผิดปกติ ควบคุมสิทธิ์การเข้าถึง และคำนวณค่าตอบแทนร้อยละ 10
• ระดับจัดเก็บข้อมูล (Data Storage Tier): ฐานข้อมูล MariaDB/MySQL (InnoDB Engine) เข้ารหัสภาษาแบบ utf8mb4 รองรับธุรกรรมที่ถูกต้องครบถ้วน (ACID)
• ระดับการเชื่อมต่อภายนอก (Integration Tier): มาตรฐานสร้างพร้อมเพย์ QR Code (EMVCo), การสแกนบาร์โค้ดผ่านกล้องเว็บแคม และการส่งออกข้อมูลสถิติเป็นไฟล์ Excel
