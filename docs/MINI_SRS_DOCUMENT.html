โครงการระบบบริหารจัดการน้ำประปาหมู่บ้านวังยาง
(Smart Village Waterworks Management System)

กองทุนระบบการประปาหมู่บ้านวังยาง หมู่ที่ 3 ตำบลวังยาง อำเภอวังยาง จังหวัดนครพนม
รหัสโครงงาน: SE-2567-WTR-MINI | ฉบับเสนอคณะกรรมการตรวจประเมินผลงาน
1. บทสรุปผู้บริหารและความเป็นมาของโครงงาน (Executive Summary)

กิจการประปาหมู่บ้านวังยาง หมู่ที่ 3 ตำบลวังยาง อำเภอวังยาง จังหวัดนครพนม ให้บริการจ่ายน้ำประปาแก่ประชาชนจำนวน 400 ครัวเรือน เดิมคณะกรรมการบริหารกิจการประปาใช้ระบบการจดบันทึกด้วยสมุดกระดาษ ทำให้ประสบปัญหาหลายประการ ได้แก่ การจดเลขอ่านมาตรวัดน้ำคลาดเคลื่อน ปัญหาตัวเลขย้อนกลับ การคำนวณค่าน้ำล่าช้า การติดตามหนี้ค้างชำระไม่เป็นระบบ และการจัดทำหลักฐานการเบิกจ่ายเงินค่าตอบแทนผู้จัดเก็บร้อยละ 10 ขาดความคล่องตัวและตรวจสอบย้อนหลังได้ยาก

คณะผู้จัดทำจึงได้พัฒนาระบบสารสนเทศบนเว็บด้วยภาษา PHP ร่วมกับระบบจัดการฐานข้อมูล MySQL เพื่อสนับสนุนการปฏิบัติงานแบบครบวงจร ครอบคลุมการจัดทำทะเบียนผู้ใช้น้ำพร้อมรหัส QR Code ติดหน้าบ้าน การเดินจดบันทึกมาตรวัดน้ำภาคสนามตามเส้นทางจริง (แบบ ป.17) การรับชำระเงินและออกใบเสร็จรับเงิน (แบบ ป.31/32) การสร้างภาพ QR Code ชำระเงินผ่านระบบพร้อมเพย์ การควบคุมบัญชีลูกหนี้ค้างชำระ (แบบ กค.4) และการคำนวณใบสำคัญเบิกจ่ายค่าตอบแทนผู้จัดเก็บร้อยละ 10 เพื่อเพิ่มประสิทธิภาพ ความถูกต้อง และความโปร่งใสของกองทุน

3. ข้อกำหนดความต้องการเชิงหน้าที่ของระบบ (Functional Requirements Matrix)

ระบบประกอบด้วย 10 ฟังก์ชันงานหลักที่ครอบคลุมกระบวนการตั้งแต่การจดบันทึกข้อมูลจนถึงการปิดงบดุลประจำเดือน:

ตารางที่ 2 ตารางสรุป 10 ข้อกำหนดความต้องการเชิงหน้าที่ (Functional Requirements)
รหัส ชื่อฟังก์ชันงาน ข้อมูลนำเข้า (Inputs) การประมวลผลและผลลัพธ์ (Outputs) ไฟล์ระบบ (PHP)
FR-01 ทะเบียนผู้ใช้น้ำและสติกเกอร์ QR Code ชื่อ-สกุล, บ้านเลขที่, โซน, หมายเลขโทรศัพท์, ลำดับเส้นทาง สร้างรหัสผู้ใช้น้ำอัตโนมัติ (WY-xxx) และพิมพ์แผ่นสติกเกอร์ QR Code ติดหน้าบ้าน 4 รูปแบบ register.php
print_qr_labels.php
FR-02 การจดบันทึกมาตรวัดน้ำภาคสนาม (ป.17) รอบเดือน/ปี, รหัสผู้ใช้น้ำ, เลขอ่านมาตรวัดน้ำครั้งนี้ เรียงลำดับตามเส้นทางเดินจริง สแกนกล้อง QR Code คำนวณหน่วยใช้สด แสดงแถบความคืบหน้า meter_reading.php
api/readings.php
FR-03 การคำนวณค่าน้ำและตรวจจับค่าผิดปกติ เลขอ่านครั้งก่อน-ครั้งนี้, อัตราต่อหน่วย, ค่าบำรุงรักษา สูตร (หน่วย x 7) + 10 + หนี้ค้างเก่า แจ้งเตือนกรณีเลขถอยหลังหรือใช้น้ำพุ่งสูงเกิน 3 เท่า api/readings.php
api/cycles.php
FR-04 การค้นหาข้อมูลค่าน้ำสำหรับประชาชน หมายเลขโทรศัพท์ 10 หลัก หรือบ้านเลขที่ ค้นหาเร็วไม่เกิน 0.05 วินาที แสดงรายการค้างชำระและปุ่มเปิดภาพ QR Code ชำระเงิน index.php
portal_citizen.php
FR-05 การรับชำระเงินและออกใบเสร็จ (ป.31/32) รหัสผู้ใช้น้ำ, รอบบิล, จำนวนเงินที่รับชำระ บันทึกสถานะชำระแล้วทันที ออกรหัสใบเสร็จ และเปิดหน้าพิมพ์ใบเสร็จรับเงิน ป.31/32 ในคลิกเดียว finance_billing.php
api/receipts.php
FR-06 การสร้าง QR Code ชำระเงินผ่านพร้อมเพย์ ยอดเงินสุทธิที่ต้องชำระ, หมายเลขบัญชีกองทุน สร้างภาพ QR Code ตามมาตรฐาน EMVCo ตรงตามยอดสตางค์จริง สแกนโอนผ่านทุกแอปธนาคาร api/receipts.php
index.php
FR-07 การควบคุมลูกหนี้ค้างชำระ (แบบ กค.4) รอบบิลค้างชำระ, ตัวกรองอายุหนี้ 1/2/3+ เดือน รายงานจัดกลุ่มอายุหนี้ พิมพ์หนังสือเตือนกำหนดชำระ 7 วัน และมีปุ่มลัดสลับไปตัดรับเงินทันที finance_billing.php
api/arrears.php
FR-08 การจัดทำใบสำคัญเบิกจ่ายค่าตอบแทน 10% ยอดเงินที่รับชำระจริงในงวด, หมวดค่าใช้จ่ายกองทุน คำนวณค่าตอบแทนร้อยละ 10 อัตโนมัติ จัดทำใบสำคัญเบิกจ่าย 8 หมวด พร้อมตัวอักษรบาทไทย finance_billing.php
api/vouchers.php
FR-09 รายงานงบดุลประจำเดือนและสถิติน้ำสูญเสีย ข้อมูลสรุปปิดงวดบัญชี, ปริมาณน้ำสูบผลิต สรุปรายรับ-รายจ่าย ยอดคงเหลือ บัญชีเงินสด/ธนาคาร อัตราน้ำสูญเสีย NRW และส่งออก Excel executive_reports.php
api/export_excel.php
FR-10 การรับแจ้งเหตุน้ำรั่ว-ท่อแตกและติดตามงาน ชื่อผู้แจ้ง, หมายเลขโทรศัพท์, จุดเกิดเหตุ บันทึกรายการแจ้งเหตุ แสดงการแจ้งเตือนช่าง และอัปเดตสถานะการเข้าซ่อมแซมจนแล้วเสร็จ index.php
api/tickets.php

4. สถาปัตยกรรมระบบและภาพหน้าจอต้นแบบ (Architecture & Prototypes)

ระบบถูกออกแบบตามสถาปัตยกรรมซอฟต์แวร์ 4 ระดับ (4-Tier Software Architecture) ประกอบด้วย:

• ระดับส่วนติดต่อผู้ใช้ (Presentation Tier): Responsive Web พัฒนาด้วย HTML5, CSS3, JavaScript และ Bootstrap 5 รองรับทั้งคอมพิวเตอร์สำนักงานและสมาร์ตโฟน
• ระดับตรรกะการประมวลผล (Application Tier): ภาษา PHP 8 ทำหน้าที่คำนวณค่าน้ำ ตรวจจับค่าผิดปกติ ควบคุมสิทธิ์การเข้าถึง (RBAC) และคำนวณค่าตอบแทนร้อยละ 10
• ระดับการจัดเก็บข้อมูล (Data Storage Tier): MariaDB 10.4 / MySQL (InnoDB Engine, utf8mb4) รองรับธุรกรรมที่ถูกต้องครบถ้วน (ACID) และมีระบบติดตั้งฐานข้อมูลอัตโนมัติ (Zero-Config DB)
• ระดับการเชื่อมต่อภายนอก (Integration Tier): มาตรฐานสร้างพร้อมเพย์ QR Code (EMVCo), การสแกนผ่านกล้อง และการส่งออกรายงานเป็นไฟล์ Excel

5. การตรวจสอบความถูกต้องและการรับรองโครงงาน (Verification & Sign-Off)

ระบบได้รับการตรวจสอบความถูกต้องและความพร้อมในการนำไปใช้งานจริงตามเกณฑ์มาตรฐานทางวิศวกรรมซอฟต์แวร์:

ตารางที่ 3 รายการตรวจสอบความถูกต้องและผลการทดสอบระบบ (Verification Checklist)
รายการตรวจสอบ (Checklist) เกณฑ์และมาตรฐานการประเมิน ผลการประเมิน
ความถูกต้องของไวยากรณ์ PHP ทดสอบรันคำสั่ง php -l ครบทั้ง 25 ไฟล์ในระบบ ผ่านเกณฑ์ 100% (ไม่มีข้อผิดพลาด)
ระบบฐานข้อมูลเริ่มต้น สร้างฐานข้อมูลและตารางอัตโนมัติผ่าน api/db.php เมื่อเริ่มใช้งานครั้งแรก ผ่านเกณฑ์ (ทำงานสมบูรณ์)
ความมั่นคงปลอดภัยของข้อมูล ใช้คำสั่ง PDO Prepared Statements 100% ป้องกัน SQL Injection ผ่านเกณฑ์มาตรฐาน OWASP
การสำรองข้อมูลฉุกเฉิน สามารถสำรองฐานข้อมูลเป็นไฟล์ .sql ผ่าน api/backup.php ในคลิกเดียว ผ่านเกณฑ์ (พร้อมใช้งาน)
ความสอดคล้องกับต้นแบบ Axure หน้าจอระบบจริงสอดคล้องกับ Wireframe ทั้ง 31 หน้าจอในไฟล์ .rp ผ่านเกณฑ์ (ตรงตามต้นแบบ)
