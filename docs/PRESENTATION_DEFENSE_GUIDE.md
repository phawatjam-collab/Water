### 🎙️ สไลด์ที่ 2: สถาปัตยกรรมระบบ 4-Tier และความพร้อมใช้งานจริง (Architecture & Deployment)
> *"ในเชิงวิศวกรรมซอฟต์แวร์ เราออกแบบระบบนี้ภายใต้ <strong>4-Tier Enterprise Architecture</strong> อย่างเป็นทางการครับ:*  
> - **Tier 1 (Presentation):** *Responsive Web UI รองรับทั้งคอมพิวเตอร์และมือถือ มีระบบค้นหาเร็วด้วยเบอร์โทรศัพท์ และสแกนกล้อง QR Code หน้าบ้าน*  
> - **Tier 2 (Application Logic):** *ประมวลผลด้วย PHP 8 Core มีเอนจินคำนวณค่าน้ำ 7 บาท + ค่าบำรุง 10 บาท, เอนจินตรวจจับตัวเลขผิดปกติ, เอนจินแปลงบาทไทย, และเอนจินซิงค์ค่าตอบแทน 10%*  
> - **Tier 3 (Data Persistence):** *ฐานข้อมูล MariaDB/MySQL Engine แบบ InnoDB รองรับธุรกรรม ACID 100%*  
> - **Tier 4 (Integration):** *เชื่อมต่อ QR พร้อมเพย์มาตรฐาน EMVCo และระบบส่งออก Excel ครับ*  
> *ที่สำคัญ ระบบนี้รองรับสภาพแวดล้อมจริงได้ 2 รูปแบบ คือจะติดตั้งบนคอมพิวเตอร์สำนักงานแบบ Local On-Premise LAN เพื่อทำงานแบบออฟไลน์ 100% โดยไม่มีค่าใช้จ่าย หรือจะขึ้น Cloud VPS ราคาประหยัดเพื่อให้ชาวบ้านตรวจค่าน้ำได้ 24 ชั่วโมงก็ได้ครับ พร้อมระบบ Zero-Config ที่สร้างฐานข้อมูลอัตโนมัติเมื่อเปิดครั้งแรกครับ"*

## 3. คลังคำถาม-คำตอบปราบเซียนจากคณะกรรมการ (Professor Defense Q&A)

### Q1: ทำไมกลุ่มคุณถึงเลือกใช้ PHP Native แทนที่จะใช้ Modern Framework เช่น Laravel หรือ React?
> **แนวทางการตอบ:**  
> *"เป็นคำถามที่ตรงจุดมากครับ เหตุผลหลักคือ **สภาพแวดล้อมจริงของสำนักงานประปาหมู่บ้านชนบท (Target Operational Environment)** ครับ:*  
> 1. *คอมพิวเตอร์ที่ทำการหมู่บ้านเป็นเครื่องสเปกพื้นฐาน (เช่น Core i3, RAM 4GB) และผู้ดูแลระบบคือผู้ใหญ่บ้านหรือเหรัญญิก ไม่ใช่ Software Engineer หากใช้ Laravel หรือ Node.js การติดตั้งจะต้องพึ่งพา `composer install`, `npm run build`, Docker และต้องมีอินเทอร์เน็ตความเร็วสูงในการอัปเดต ซึ่งไม่สอดคล้องกับบริบทชุมชน*  
> 2. *การใช้ PHP 8 Native ร่วมกับ Vanilla JS ทำให้ระบบมีขนาดเบามาก (Low Overhead), โหลดเร็วในเวลาต่ำกว่า 0.2 วินาที, รันผ่าน XAMPP ได้ทันทีโดยไม่ต้องตั้งค่าเพิ่มเติม (Zero-Config), และสามารถทำงานแบบ Offline 100% ได้อย่างเสถียรที่สุดครับ"*

---

### Q2: ถ้าเกิดเหตุไฟดับหรือระบบขัดข้องขณะกำลังบันทึกข้อมูลการเงิน ข้อมูลจะสูญหายหรือเสียหายหรือไม่?
> **แนวทางการตอบ:**  
> *"ระบบของเราป้องกันปัญหานี้ไว้ 2 ชั้นครับ:*  
> 1. *ชั้นฐานข้อมูล: เราใช้ MariaDB/MySQL Storage Engine แบบ **InnoDB** ซึ่งรองรับคุณสมบัติ **ACID (Atomicity, Consistency, Isolation, Durability)** การทำธุรกรรมการเงินทุกจุดจะทำงานอยู่ภายใต้ Database Transaction หากระบบดับกลางคัน ข้อมูลจะถูก Rollback อัตโนมัติ ไม่เกิดภาวะข้อมูลค้างคาหรือตัดยอดซ้ำ*  
> 2. *ชั้น Disaster Recovery: เรามีเอนจิน `api/backup.php` ที่ให้เหรัญญิกกดสำรองฐานข้อมูลออกมาเป็นไฟล์ `.sql` ลง Flash Drive ได้ในคลิกเดียวทุกวัน ทำให้สามารถกู้คืนระบบกลับมาได้ภายใน 5 นาที (RTO < 5 นาที) ครับ"*

---

### Q3: ระบบป้องกันปัญหาการปลอมแปลงสลิป หรือการแอบแก้ไขยอดเงินค่าน้ำอย่างไร?
> **แนวทางการตอบ:**  
> *"เราใช้มาตรการควบคุมความปลอดภัย 3 ด้านครับ:*  
> 1. *การใช้ **Role-Based Access Control (RBAC)**: สมาชิกและประชาชนทั่วไปมีสิทธิ์เพียงแค่เรียกดู (Read-Only) และสร้างคำขอแจ้งเหตุเท่านั้น ไม่มีสิทธิ์ส่งคำสั่งอัปเดตสถานะชำระเงิน*  
> 2. *การใช้ **PDO Prepared Statements 100%**: ทุกคำสั่ง SQL มีการผูกตัวแปร Parameter Binding ป้องกันการยิง SQL Injection เพื่อลักลอบแก้ข้อมูล*  
> 3. *ระบบ **Audit Trail & Receipt Numbering**: การตัดชำระเงินทุกครั้งจะบันทึกเวลา `paid_at = NOW()` และออกเลขที่ใบเสร็จ `RC-YYYYMM-XXX` ที่รันต่อเนื่องกันแบบผูกพันทางบัญชี ทำให้สามารถตรวจสอบย้อนกลับได้เสมอครับ"*

---

### Q4: ทำไมระบบถึงมี 'ฎีกาเบิกจ่าย 10%' สิ่งนี้จำเป็นอย่างไรในระบบประปาหมู่บ้าน?
> **แนวทางการตอบ:**  
> *"การมีฎีกา 10% คือสิ่งที่ทำให้ระบบนี้ **สอดคล้องกับระเบียบการบริหารกิจการประปาหมู่บ้านของกระทรวงมหาดไทย** อย่างแท้จริงครับ:*  
> *ในทางปฏิบัติ ผู้จัดเก็บค่าน้ำคือชาวบ้านที่ต้องเสียเวลาและค่าน้ำมันเดินเท้าตามซอยเพื่อเก็บเงิน ระเบียบกองทุนจึงกำหนดให้มีเงินรางวัลหรือค่าตอบแทนการจัดเก็บอัตราร้อยละ 10 จาก 'ยอดเงินที่จัดเก็บได้จริง' (ไม่ใช่ยอดเรียกเก็บ)*  
> *ในระบบเดิม เหรัญญิกต้องมานั่งกดเครื่องคิดเลขและหักเงินสดกันเองโดยไม่มีเอกสาร ทำให้เกิดข้อพิพาทความไม่โปร่งใส ระบบของเราจึงสร้างเอนจินคำนวณยอด 10% จากบิลที่ชำระแล้วโดยอัตโนมัติ และพิมพ์ใบสำคัญรับเงินที่มีลายมือชื่อ 3 ฝ่าย (ผู้รับเงิน, เหรัญญิก, ประธานกองทุน) ทำให้เกิดธรรมาภิบาลและความโปร่งใสในการตรวจสอบบัญชีชุมชนครับ"*
